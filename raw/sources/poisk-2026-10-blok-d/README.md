# Поиск 2026-10, блок D: право (гл. 17) и два варианта блюда (гл. 19)

Служебная записка к иммутабельному каталогу. Не доклад и не wiki-страница.

- **Что это.** Реестр внешних источников и сверок, выполненных агентом по прямой просьбе Евгения Чистякова (09.10.2026): «закрыть проблемы новыми исследованиями и поиском в интернет, зарубежные источники переводить на русский язык».
- **Зачем.** Опора для новой редакции глав 17 «Право Российской Федерации» и 19 «Два варианта блюда» (`doklad-v2/17_pravo.md`, `doklad-v2/19_dva_varianta.md`).
- **Дата проверки:** 09.10.2026. Позже — перепроверять (особенно ст. 6.6 КоАП: на consultant.ru отмечены изменения, не вступившие в силу).
- **Метод.** Веб-поиск и чтение страниц правовых баз (consultant.ru — статьи законов; rulaws.ru — текст СанПиН 3590-20), сайта ООН, страниц издателей и репозиториев. garant.ru, legalacts.ru и normativ.kontur.ru в день проверки не открылись (ошибка загрузки). publication.pravo.gov.ru по СанПиН 4282-26 не найден поиском; реквизиты взяты из вторичных страниц (Контур, NormaCS). Ключевые формулировки даны в оригинале и в переводе агента.
- **Чего здесь нет.** Полных текстов статей: PubMed / PMC закрыты капчей; клинические числа взяты из рефератов на страницах издателей и университетских репозиториев. Где читался только реферат, это сказано.
- **Класс.** Российские НПА — норма в пределах процитированного текста. Приказы Минздрава (S073) — реквизиты по вторичному обзору юридической фирмы. Зарубежные больничные исследования — клинические данные иной организационной среды; перенос на российские ДСО и ПНИ — толкование, не факт.
- **Номера S:** выделенный диапазон S070–S079; использованы S070–S075.
