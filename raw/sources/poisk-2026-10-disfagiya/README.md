# Поиск 2026-10: дисфагия, удушье, текстуры, гигиена рта

Служебная записка к иммутабельному каталогу. Не доклад и не wiki-страница.

- **Что это.** Реестр внешних источников, найденных агентом по прямой просьбе Евгения Чистякова (тред проекта «Вариативное меню», 09.10.2026): «закрыть проблемы новыми исследованиями и поиском в интернет, зарубежные источники переводить на русский язык».
- **Зачем.** Опора для новой редакции главы 10 «Дисфагия» (`doklad-v2/10_disfagiya.md`) и закрытия части пунктов `wiki/gaps.md`.
- **Дата проверки:** 09.10.2026. Позже — перепроверять.
- **Метод.** Веб-поиск и чтение страниц издателя или репозитория. Каждое число в [`istochniki.md`](istochniki.md) взято со страницы, указанной рядом. Ключевые формулировки даны в оригинале и в русском переводе агента.
- **Чего здесь нет.** Полных текстов статей. Страницы PubMed / PMC в день поиска закрывались капчей, Europe PMC — лимитом запросов. Там, где читался только реферат, это сказано.
- **Класс.** Клинические данные зарубежных популяций. Перенос на российские ДСО и ПНИ — толкование, не факт.
