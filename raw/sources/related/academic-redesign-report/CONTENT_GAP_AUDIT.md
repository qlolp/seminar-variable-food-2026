## Ограничения аудита

1. Проверка URL не проводилась автоматически (отсутствуют инструменты).
2. Юридическая верификация нормативных актов проведена по доступным онлайн-источникам.
3. Медицинские утверждения проверены по общедоступным клиническим рекомендациям.
4. Финансовые расчёты remain иллюстративными.
