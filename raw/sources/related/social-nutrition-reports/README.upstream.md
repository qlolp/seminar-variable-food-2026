# Вариативное питание в стационарных организациях социального обслуживания

Научно-аналитические доклады о вариативном питании в стационарных организациях социального обслуживания для лиц с психическими расстройствами.

Подготовлено для межрегионального методического семинара-совещания «Пространство Новых Идей 2.0» (25–27 августа 2026, Санкт-Петербург).

## Каталоги

- **academic_redesign_report/** — академическая переработка доклада (две версии: официальная TNR 14pt + современная академическая)
- **seminar_variable_food_2026/** — основной доклад «Не просто накормить» + семинарский пакет (выступление, презентация, раздаточные материалы)
- **report_variable_menu_pni/** — первый доклад «Вариативное меню в стационарных организациях социального обслуживания»
- **report_international_nutrition/** — каркас международного доклада

## Верифицированные источники

1. IDDSI Framework — Cichero et al., Dysphagia 2017, PMID 27913916
2. CQC Regulation 14 — SI 2014/2936, legislation.gov.uk
3. Конвенция ООН о правах инвалидов (CRPD) — ООН, 2006
4. Письмо Минтруда России — mintrud.gov.ru/events/1481

- Веб-доступ частичный; ряд российских нормативных актов не верифицирован по первоисточнику
