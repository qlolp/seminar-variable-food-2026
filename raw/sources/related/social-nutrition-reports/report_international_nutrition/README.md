# Международный опыт организации питания в учреждениях длительного проживания для лиц с психическими расстройствами

Научно-аналитический доклад — КАРКАС (структура и перечень источников для верификации)

## Статус документа
**Каркас.** Настоящий документ содержит структуру доклада, оглавление, методологию, перечень рассматриваемых стран и документов, шаблоны разделов. Содержательные утверждения о конкретных странах, нормативных актах и практиках **отсутствуют** и будут добавлены только после верификации по первоисточникам при наличии стабильного веб-доступа. В условиях частичного/нестабильного веб-доступа выдумывать факты, номера документов, цитаты и практики запрещено требованиями к достоверности.

## Проверено по состоянию на
22 июля 2026 года. Веб-доступ частичный и нестабильный: webfetch к конкретным страницам WHO, CQC возвращает 404; OECD, CDC, Socialstyrelsen, AIHW, HIQ — timeout/403. Ни один первоисточник не открыт в полном объёме; верификация не выполнена.
