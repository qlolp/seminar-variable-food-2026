# Раздел 4. Понятийный аппарат

**Статус: каркас.** Определения будут уточнены по верифицированным источникам. Приведённые ниже термины являются предварительными рабочими и требуют подтверждения.

## Планируемые понятия (с оригинальными и русскими названиями)
Для каждого термина после верификации будет указано: оригинальное название; русский перевод; источник определения; применимость к объекту исследования; ограничения интерпретации.

| Термин (оригинал) | Русский перевод (предварительно) | Источник определения (требует проверки) | Применимость |
|-------------------|----------------------------------|------------------------------------------|--------------|
| long-term care | длительный уход | ВОЗ/OECD (требует проверки) | требует проверки |
| residential care | стационарный уход/проживание | национальные регуляторы (требует проверки) | требует проверки |
| supported living | сопровождаемое проживание | национальные регуляторы (требует проверки) | требует проверки |
| group home | группа сопровождаемого проживания | национальные регуляторы (требует проверки) | требует проверки |
| person-centered care | персонцентрированная помощь | национальные стандарты (требует проверки) | требует проверки |
| supported decision-making | поддерживаемое принятие решений | Конвенция ООН о правах инвалидов ст.12 (требует проверки) | требует проверки |
| malnutrition | недостаточность питания | ВОЗ/ESPEN (требует проверки) | требует проверки |
| dehydration | обезвоживание | клинические рекомендации (требует проверки) | требует проверки |
| dysphagia | дисфагия | клинические рекомендации (требует проверки) | требует проверки |
| texture-modified diet | текстурно-модифицированный рацион | IDDSI (требует проверки) | требует проверки |
| provider | поставщик услуг | национальное законодательство (требует проверки) | требует проверки |
| regulator | регулятор | национальное законодательство (требует проверки) | требует проверки |

## Разграничение смежных понятий
Будут разграничены: long-term care vs acute care; residential care vs home care; supported living vs institutional care; person-centered care vs traditional care. Разграничение будет основано на верифицированных определениях.

## Ограничение
Без верификации источников определения не могут использоваться как установленные.
