# Инструкция по печати доклада

## 📄 Быстрый способ печати

### Вариант 1: Печать HTML (рекомендуется)

1. **Откройте файл в браузере:**
   ```
   output/report-print.html
   ```

2. **Нажмите Ctrl+P** (или Cmd+P на Mac)

3. **Настройте параметры печати:**
   - Размер бумаги: **A4**
   - Поля: **Обычные** или **Минимальные**
   - Масштаб: **100%**
   - ✅ Включить: **Фоновая графика**
   - ✅ Включить: **Колонтитулы**

4. **Нажмите "Печать"** или **"Сохранить как PDF"**

### Вариант 2: Печать Markdown через VS Code

1. **Откройте файл:**
   ```
   output/report.md
   ```

2. **Откройте предпросмотр Markdown:**
   - Нажмите `Ctrl+Shift+V` (или `Cmd+Shift+V` на Mac)
   - Или нажмите на иконку предпросмотра в правом верхнем углу

3. **Распечатайте предпросмотр:**
   - Нажмите `Ctrl+P`
   - Выберите **"Печать"**

### Вариант 3: Конвертация в PDF через онлайн-сервисы

1. **Загрузите файл на сервис:**
   - https://markdown-to-pdf.com/
   - https://www.markdowntopdf.com/
   - https://dillinger.io/

2. **Скачайте PDF** и распечатайте

## 🖨️ Рекомендуемые настройки печати

| Параметр | Значение |
|----------|----------|

| Параметр | Значение |

## 🔧 Устранение проблем

### Таблицы не помещаются на страницу:
1. Уменьшите масштаб до **90-95%**
2. Или измените ориентацию на **Альбомную** для широких таблиц
3. Или используйте **"Печать выделения"** для широких таблиц отдельно

### Текст слишком мелкий:
1. Увеличьте масштаб до **110-120%**
2. Или выберите **"Подогнать по странице"**

### Нет колонтитулов:
1. Включите опцию **"Колонтитулы"** в настройках печати
2. Или добавьте их вручную в Word/LibreOffice

### Пустые страницы между главами:
1. Это нормально — разрывы страниц добавлены автоматически
2. Если нужно убрать: отключите `page-break-before: always` в CSS

## 📱 Альтернативные способы печати

### Через LibreOffice Writer:
1. Откройте `output/report.md` в LibreOffice
2. Используйте расширение **Markdown Import**
3. Настройте стили и распечатайте

### Через Microsoft Word:
1. Откройте `output/report.md` в Word
2. Word автоматически конвертирует Markdown
3. Настройте параметры страницы и распечатайте

### Через Google Docs:
1. Загрузите `output/report.md` в Google Drive
2. Откройте с помощью Google Docs
3. Файл → Скачать как → PDF
4. Распечатайте PDF

## 🆘 Если что-то пошло не так

### HTML не открывается:
- Попробуйте другой браузер (Chrome, Firefox, Edge)
- Проверьте, что файл существует: `output/report-print.html`

### Печать не работает:
- Проверьте подключение принтера
- Попробуйте сохранить как PDF сначала
- Перезапустите браузер

### Таблицы обрезаются:
- Используйте масштаб 90%
- Или поверните страницу в альбомную ориентацию
- Или распечатайте широкие таблицы отдельно
