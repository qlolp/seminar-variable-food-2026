# Вопросы, требующие индивидуального заключения специалиста

**Перед внедрением вариативного меню необходимо получить индивидуальные заключения по следующим вопросам.**

## Юрист (по социальному обслуживанию)
1. Применимость к конкретному учреждению положений ФЗ-442, ФЗ-323, ФЗ-3185-1, ФЗ-48, ФЗ-44, ФЗ-152, БК РФ, ТК РФ, КоАП, УК в актуальных редакциях.
2. Актуальная редакция регионального закона о социальном обслуживании и порядка предоставления стационарных социальных услуг.
3. Действующие натуральные нормы питания в субъекте РФ.
4. Предельно допустимый размер платы за стационарные социальные услуги в субъекте РФ.
5. Правовой статус выбора еды как повседневного бытового решения; пределы участия опекуна.
6. Правомерность локального акта о вариативном меню без отдельного регионального разрешения.
7. Необходимость согласования с учредителем; объём согласования.

## Юрист (по психиатрическому законодательству и опеке)
1. Применимость Закона РФ «О психиатрической помощи и гарантиях прав граждан при её оказании» к организации питания.
2. Разграничение социального обслуживания и медицинской деятельности в части питания.
3. Порядок учёта мнения недееспособного при выборе еды.
4. Разрешение конфликта интересов при учреждении-опекуне.
5. Пределы согласия опекуна на повседневный бытовой выбор.

## Врач-психиатр
1. Оценка состояния каждого проживающего применительно к способности принимать пищу и делать выбор.
2. Влияние психофармакотерапии на аппетит, глотание, метаболизм (по надёжным источникам).
3. Тактика при отказе от еды, пикацизме, быстром заглатывании.

## Врач-диетолог
1. Расчёт КБЖУ для каждого варианта с обеспечением равенства пищевой ценности.
2. Соответствие натуральным нормам субъекта РФ.
3. Состав технологических карт.
4. Профилактика недостаточности питания и обезвоживания.

## Специалист по дисфагии / логопед / гастроэнтеролог
1. Оценка риска аспирации для каждого проживающего.
2. Назначение модифицированной консистенции.
3. Необходимость сопровождения во время еды.

## Бухгалтер государственного/бюджетного учреждения
1. Учётная политика в части питания и вариативного меню.
2. Раздельный учёт расходов.
3. Применимые счета и федеральные стандарты.
4. Порядок списания, инвентаризации, хранения документов.
5. Формы первичных документов (обязательные реквизиты vs установленные формы).

## Специалист по ФЗ-44
1. Применимость ФЗ-44 vs ФЗ-223 к конкретному учреждению.
2. Выбор способа закупки для продуктов вариативного меню.
3. Описание объекта закупки с обеспечением эквивалентности и без ограничения конкуренции.
4. Основания закупки у единственного поставщика для специализированных продуктов.
5. Порядок приёмки и экспертизы.
6. Риски дробления закупок и квалификации.

## Орган опеки
1. Порядок учёта мнения недееспособного при выборе еды.
2. Пределы согласия опекуна.
3. Разрешение конфликта интересов при учреждении-опекуне.
4. Участие органа опеки в комиссии по питанию.

## Учредитель
1. Согласование пилотного проекта.
2. Корректировка государственного задания.
3. Дополнительные ассигнования.
4. Согласование локальных актов.
5. Включение в планы внутреннего финансового контроля.

## Специалист по персональным данным
1. Правовое основание обработки сведений о диагнозах, аллергиях, диетах, предпочтениях.
2. Политика обработки персональных данных.
3. Объём собираемых данных и сроки хранения.
4. Уведомление Роскомнадзора (при необходимости).

## Орган Роспотребнадзора
1. Разъяснения по применению санитарных правил при нескольких линиях раздачи и модифицированной консистенции.
2. Требования к маркировке, хранению, температурным режимам.

**Без получения указанных заключений внедрение вариативного меню недопустимо.**
