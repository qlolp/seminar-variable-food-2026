# Практические рекомендации (одна страница)

**Предварительно; требует адаптации к конкретному субъекту РФ и учреждению.**

## Для директора (0–6 месяцев)
1. Правовой аудит (запрос актов органа соцзащиты субъекта РФ).
2. Обращение к учредителю с обоснованием пилота.
3. Медицинская оценка проживающих (ограничения, способность к выбору, дисфагия).
4. Локальные акты (положение, приказ, комиссия, формы, журналы).
5. Финансовое обоснование (смета, технологические карты, расчёт натуральных норм).
6. Обучение персонала.
7. Пилот на одном отделении; ежедневный мониторинг.

## Для учредителя
1. Рассмотреть обращение учреждения.
2. Корректировка госзадания в части показателей качества питания.
3. Дополнительные ассигнования при обосновании.
4. Региональные методические рекомендации.

## Для Минтруда России
1. Федеральные методические рекомендации по организации питания с разделом о вариативном меню.
2. Обобщение регионального опыта.

## Для Минздрава России
1. Клинические рекомендации по питанию при дисфагии и модифицированной консистенции.
2. Оценка риска аспирации.

## Для Роспотребнадзора
1. Разъяснения о допустимости нескольких линий раздачи и модифицированной консистенции.

## Что нельзя делать
- Внедрять без согласования при удорожании.
- Нарушать натуральные нормы.
- Использовать еду как поощрение/наказание.
- Принудительно кормить без медицинского основания.
- Формально имитировать выбор.
- Игнорировать медицинские ограничения.
- Сокрывать инциденты.
- Внедрять без обучения персонала.
- Выбирать за проживающего, который может выбрать сам.
- Подделывать записи.

## Ключевое
Превентивные меры всегда дешевле реактивных. Документы защитного контура — основа подтверждения добросовестности.
