## 🖨️ Как распечатать доклад

### Быстрый способ (рекомендуется):

1. Откройте файл **report-print.html** в браузере
2. Нажмите **Ctrl+P** (или Cmd+P на Mac)
3. Настройте параметры:
   - Размер бумаги: **A4**
   - Поля: **Обычные**
   - Масштаб: **100%**
4. Нажмите **"Печать"** или **"Сохранить как PDF"**

Подробная инструкция: см. [PRINT_INSTRUCTIONS.md](../PRINT_INSTRUCTIONS.md)

## 🔄 Генерация других форматов

### Из Markdown в PDF:
```bash
# Через pandoc (если установлен)
pandoc report.md -o report.pdf --pdf-engine=xelatex

# Через weasyprint (если установлен)
weasyprint report-print.html report.pdf

# Через wkhtmltopdf (если установлен)
wkhtmltopdf report-print.html report.pdf
```

### Из Markdown в DOCX:
```bash
# Через pandoc
pandoc report.md -o report.docx

# Онлайн-конвертеры
# https://cloudconvert.com/md-to-docx
```

### Из Markdown в PPTX:
```bash
# Через pandoc
pandoc presentation_script.md -o presentation.pptx
```
