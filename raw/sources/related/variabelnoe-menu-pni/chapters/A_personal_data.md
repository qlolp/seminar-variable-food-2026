# Приложение А. Подробный анализ защиты персональных данных при внедрении вариативного меню

## A.1. Правовая основа обработки персональных данных

### Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных»

Организация социального обслуживания, внедряющая вариативное меню, неизбежно обрабатывает персональные данные проживающих, включая:

**Общие персональные данные:**
- фамилия, имя, отчество;
- дата рождения;
- идентификатор проживающего (номер койко-места, номер в реестре);
- номер отделения.

**Специальные категории персональных данных (ст. 10 ФЗ № 152):**
- сведения о состоянии здоровья;
- диагнозы;
- информацию об аллергиях;
- информацию о пищевых непереносимостях;
- данные о назначенных диетах;
- данные о необходимости текстурной модификации;
- данные о риске аспирации;
- данные о лекарственной терапии, влияющей на питание.

### Правовые основания обработки

Обработка персональных данных проживающих в контексте вариативного меню может основываться на:

1. **Согласие субъекта** (п. 1 ч. 1 ст. 6 ФЗ № 152) — для дееспособных граждан;
2. **Исполнение договора** (п. 5 ч. 1 ст. 6 ФЗ № 152) — договора о предоставлении социальных услуг;
3. **Защита жизни и здоровья** (п. 4 ч. 1 ст. 6 ФЗ № 152) — при обработке данных о здоровье для обеспечения безопасности питания;
4. **Медиико-профилактические цели** (п. 4 ч. 2 ст. 10 ФЗ № 152) — для обработки специальных категорий данных.

### Специальные категории данных

Обработка данных о здоровье для организации питания требует:

1. **Правового основания:**
   - Согласие (для дееспособных);
   - Необходимость для защиты жизни и здоровья (при невозможности получения согласия);
   - Медицинско-профилактические цели (при участии медицинского работника).

2. **Условий обработки:**
   - Обработка осуществляется лицом, профессионально занимающимся медицинской деятельностью;
   - Обязанность сохранения врачебной тайны;
   - Ограничение доступа к данным.

3. **Меры защиты:**
   - Ограничение круга лиц, имеющих доступ;
   - Хранение в защищённых условиях;
   - Уничтожение по истечении необходимости.

## A.2. Практические вопросы обработки данных

### Данные, необходимые для вариативного меню

Для организации вариативного меню пищеблок и ответственные лица должны иметь информацию о:

| Данные | Кто имеет доступ | Форма хранения |
|--------|------------------|----------------|
| Имя, номер проживающего | Персонал столовой | Журнал, карточка |
| Назначенная диета | Врач, диетолог, зав. пищеблоком | Медицинская карта, журнал диет |
| Аллергии | Врач, диетолог, зав. пищеблоком, персонал столовой | Карточка проживающего, список на стене |
| Текстурная модификация | Врач, персонал столовой | Журнал, карточка |
| Риск аспирации | Врач, персонал столовой | Журнал |
| Пищевые предпочтения | Соц. работник, персонал | Профиль предпочтений |
| Дееспособность | Директор, соц. работник, опекун | Документы |

### Минимизация данных

Принцип минимизации (ст. 5 ФЗ № 152) требует:

- собирать только те данные, которые необходимы для конкретной цели;
- не разглашать диагнозы персоналу пищеблока — достаточно информации о диете и аллергиях;
- не указывать в меню-требовании диагнозы — только номера диет;
- ограничивать доступ к медицинской информации.

### Информирование персонала

Персонал пищеблока должен знать:

- **какую** информацию: аллергии, диеты, текстурные требования;
- **но не** должен знать: диагнозы, историю болезни, дееспособность.

**Пример правильной маркировки:** «Проживающий № 47, диета № 9 (диабетическая), аллергия на орехи, консистенция — пюре».

**Пример неправильной маркировки:** «Иванов И. И., шизофрения, диабет 2 типа, аллергия на арахис».

## A.3. Документы и согласия

### Согласие на обработку

Для дееспособного проживающего:

1. Письменное согласие на обработку персональных данных;
2. Отдельное согласие на обработку данных о здоровье (специальные категории);
3. Информация о целях обработки;
4. Информация о праве отозвать согласие.

### Для недееспособного

- Согласие опекуна на обработку;
- При учреждении-опекуне — решение учреждения;
- Учёт мнения подопечного при возможности.

### Политика обработки

Учреждение обязано опубликовать политику обработки персональных данных, включающую:

- цели обработки;
- перечень обрабатываемых данных;
- перечень действий с данными;
- способы обработки;
- сроки хранения;
- порядок уничтожения;
- меры защиты.

## A.4. Информационная безопасность

### Технические меры

1. Разграничение доступа (ролевая модель);
2. Шифрование баз данных;
3. Журналирование доступа;
4. Резервное копирование;
5. Антивирусная защита;
6. Защита от несанкционированного доступа.

### Организационные меры

1. Назначение ответственного за обработку ПДн;
2. Обучение персонала;
3. Подписание обязательств о неразглашении;
4. Периодический аудит;
5. Реагирование на инциденты.

## A.5. Риски и санкции

### Риски

| Риск | Вероятность | Последствие |
|------|-------------|-------------|
| Утечка данных о здоровье | Низкая | Репутационный ущерб, штраф |
| Разглашение диагнозов персоналу | Средняя | Нарушение врачебной тайны |
| Утеря данных (сбой) | Низкая | Потеря информации о диетах |
| Несанкционированный доступ | Низкая | Утечка данных |
| Неправильная маркировка (диагноз вместо диеты) | Средняя | Нарушение приватности |

### Санкции (КоАП РФ, ст. 13.11)

| Нарушение | Штраф для должностного лица | Штраф для юридического лица |
|-----------|----------------------------|---------------------------|
| Обработка без согласия | 10 000–20 000 руб. | 15 000–75 000 руб. |
| Несоответствие целям | 5 000–10 000 руб. | 30 000–50 000 руб. |
| Непринятие мер защиты | 4 000–10 000 руб. | 25 000–50 000 руб. |
| Невыполнение требований субъекта | 4 000–8 000 руб. | 20 000–40 000 руб. |

## A.6. Рекомендации

1. **Минимизируйте данные:** персоналу пищеблока — только информация о диетах и аллергиях, не диагнозы.
2. **Разделяйте доступ:** медицинская информация — у врача, информация о питании — у пищеблока.
3. **Обучайте персонал:** о врачебной тайне и защите данных.
4. **Документируйте:** согласия, политики, журналы доступа.
5. **Аудит:** регулярная проверка соответствия обработки законодательству.
6. **Реагируйте:** при инцидентах — в установленные сроки уведомляйте Роскомнадзор.
