# Раздел 14. Бухгалтерский учёт и финансовый контроль

## Задача главы

Проанализировать особенности бухгалтерского учёта и государственного финансового контроля при вариативном меню.

---

## 14.1. Первичные документы

При вариативном меню увеличивается объём первичной документации:

1. **Меню-требование:** Документ, на основании которого выдаются продукты из кладовой для приготовления блюд. При вариативном меню меню-требование должно учитывать несколько вариантов блюд.

2. **Акт списания продуктов:** Фиксирует факт списания использованных продуктов. При вариативном меню акт должен содержать распределение продуктов по вариантам блюд.

3. **Журнал бракеража:** Фиксирует качество приготовленных блюд (включая все варианты).

4. **Журнал отказов:** Фиксирует отказы проживающих от предложенных вариантов.

5. **Формы фиксации выбора:** Документы, подтверждающие факт выбора проживающим.

### 14.1.1. Обязательные реквизиты первичных документов

В соответствии с ФЗ от 06.12.2011 № 402-ФЗ «О бухгалтерском учёте» (ст. 9, проверить актуальную редакцию) первичный учётный документ должен содержать:
- наименование документа;
- дату составления;
- наименование экономического субъекта;
- содержание хозяйственной операции;
- величину натурального и денежного измерения;
- должности лиц, ответственных за операцию;
- подписи лиц.

**Важно:** ФЗ № 402-ФЗ не устанавливает обязательных форм первичных документов. Учреждение вправе разработать собственные формы при условии соблюдения обязательных реквизитов.

---

## 14.2. Складской учёт

При вариативном меню складской учёт усложняется:
- Увеличение числа наименований продукции.
- Необходимость отслеживания сроков годности для расширенного ассортимента.
- Дополнительная маркировка.

**Рекомендуемые меры:**
1. Группировка продуктов по категориям.
2. Маркировка с указанием даты поступления.
3. Метод FIFO (First In, First Out) для всех категорий.
4. Раздельное хранение продуктов для разных вариантов (при необходимости).

---

## 14.3. Списание продуктов

### 14.3.1. Порядок списания

1. На основании меню-требования.
2. С учётом фактически приготовленных блюд (включая все варианты).
3. С указанием количества порций по каждому варианту.
4. С учётом пищевых отходов.

### 14.3.2. Особенности при вариативном меню

- Необходимо раздельное списание по вариантам блюд.
- Пищевые отходы могут различаться по вариантам.
- Замены продуктов должны фиксироваться документально.

---

## 14.4. Раздельный учёт

При совмещении вариативного и единого меню (в разных отделениях) необходим раздельный учёт:
- По отделениям.
- По видам питания (стандартное, вариативное, диетическое).
- По источникам финансирования.

---

## 14.5. Инвентаризация

При вариативном меню инвентаризация складских остатков требует:
- Увеличения объёма проверки (больше наименований).
- Проверки сроков годности для расширенного ассортимента.
- Сверки фактических остатков с учётными данными.

---

## 14.7. Типичные нарушения, выявляемые при проверках

1. Несоответствие фактического питания натуральным нормам.
2. Отсутствие или ненадлежащее ведение первичных документов.
3. Нецелевое использование бюджетных средств на питание.
4. Завышение стоимости закупаемых продуктов.
5. Нарушение складского учёта (отсутствие инвентаризации, нарушение FIFO).
6. Фактическое питание не соответствует утверждённому меню.
7. Отсутствие бракеража или формальное проведение.
8. Нарушение температурного режима хранения.
9. Использование продуктов с истёкшими сроками годности.
10. Отсутствие учёта пищевых отходов.

---

## 14.8. Документы, которые могут запросить контрольные органы

1. Утверждённое меню на период.
2. Меню-требования.
3. Акты списания продуктов.
4. Журнал бракеража.
5. Журнал температурного контроля.
6. Документы на приёмку продуктов (накладные, сертификаты).
7. Технологические карты.
8. Приказы о назначении ответственных лиц.
9. Договоры с поставщиками.
10. Акты приёмки выполненных работ.
11. Формы фиксации выбора проживающих (при вариативном меню).
12. Журнал отказов от пищи.
13. Документы по оплате труда персонала пищеблока.
14. Документы по складскому учёту.

---

## Выводы по главе

1. Вариативное меню увеличивает объём и сложность бухгалтерской документации.

2. Обязательные реквизиты первичных документов определяются ФЗ № 402-ФЗ; учреждение вправе разработать собственные формы.

3. Раздельный учёт является необходимым при совмещении моделей питания.

4. Типичные нарушения при проверках связаны с несоблюдением натуральных норм, отсутствием документации и нецелевым расходованием средств.

5. Документы вариативного меню (формы фиксации выбора, журналы) должны быть включены в перечень документов, подлежащих проверке.
