# Вариативное меню в стационарных организациях социального обслуживания для лиц с психическими расстройствами

Научно-аналитический доклад.

## Статус
**Предварительная версия.** Законодательство, официальные данные и интернет-ссылки проверены по состоянию на 22 июля 2026 года. В условиях отсутствия веб-доступа к официальным порталам Российской Федерации полная верификация источников не выполнена. Все источники помечены «требует проверки». Доклад требует верификации специалистом перед практическим применением.

## Содержание
Доклад исследует нормативно-правовую базу, региональный и международный опыт, особенности реализации, финансовое обеспечение, контроль, социальную справедливость и персональные риски руководителя при внедрении вариативного меню в стационарных организациях социального обслуживания, предназначенных для проживания лиц с психическими расстройствами.

## Объём
- 44 513 слов основного текста (report.md)
- ~126 страниц А4 (из расчёта ~350 слов/страницу, TNR 14pt, межстрочный 1.5, стандартные поля)
- Превышает минимальные требования (80 страниц / 35 000 слов)

## Ключевые выводы (кратко)
1. Вариативное меню допустимо в действующем правовом поле, но не является безусловно положительной практикой; требует системного толкования норм.
2. Наибольший уровень риска — медицинский (пищевое отравление, аспирация) и финансовый/коррупционный.
3. Директор не отвечает автоматически; вина и должностные обязанности должны быть установлены; делегирование не всегда исключает обязанность контроля.
4. Формальная имитация выбора создаёт больший риск, чем открытое отсутствие вариативного меню.
5. Превентивные меры всегда дешевле реактивных; документы защитного контура — основа подтверждения добросовестности.

## Главное ограничение
**Веб-доступ отсутствует.** Все источники требуют верификации при появлении доступа. Использование доклада как прямого руководства без индивидуальных заключений специалистов недопустимо.

## Как использовать
1. Прочитать output/executive_summary.md — краткая версия.
2. Прочитать output/director_memo.md — резюме для директора.
3. Обратиться к output/report.md — полный доклад.
4. Использовать appendices/ — шаблоны локальных документов (требуют адаптации).
5. Проверить output/specialist_questions.md — перечень вопросов для специалистов.
6. Перед внедрением — получить индивидуальные заключения юриста, врача, бухгалтера, специалиста по закупкам, органа опеки, учредителя.

## 🖨️ Печать документа

### Рекомендуемый способ:

1. Откройте файл **output/report-print.html** в браузере (Chrome, Firefox, Edge)
2. Нажмите **Ctrl+P** (или Cmd+P на Mac)
3. Настройте параметры:
   - Размер бумаги: **A4**
   - Поля: **Обычные** (или минимальные)
   - Масштаб: **100%**
   - ✅ Включить: **Фоновая графика**
   - ✅ Включить: **Колонтитулы**
4. Нажмите **"Печать"** или **"Сохранить как PDF"**

HTML-версия оптимизирована для печати:
- Автоматические разрывы страниц перед каждой главой
- Таблицы не разрываются между страницами
- Заголовки не отрываются от текста
- Профессиональные шрифты (Georgia/Times New Roman)
- Колонтитулы с названием документа и номером страницы
- Правильные поля (25мм верх/низ/лево, 20мм право)

Подробная инструкция: см. [PRINT_INSTRUCTIONS.md](PRINT_INSTRUCTIONS.md)

### Альтернативные способы:
- Через VS Code: открыть output/report.md → Ctrl+Shift+V (предпросмотр) → Ctrl+P
- Через онлайн-конвертеры: https://markdown-to-pdf.com/ или https://dillinger.io/
- Через LibreOffice/Word: открыть output/report.md и настроить стили

## Воспроизводимость
- Скрипт `python3 scripts/build_report.py` — пересборка доклада из глав и приложений.
- Скрипт `python3 scripts/build_charts.py` — генерация диаграмм (чистый Python, без внешних библиотек).
- Скрипт `python3 scripts/quality_check.py` — контроль качества.
- Скрипт `python3 scripts/validate_citations.py` — подготовка перечня ссылок для верификации.

## Конвертация в DOCX/PDF
Для конвертации output/report.md в DOCX/PDF используйте pandoc:
```
pandoc output/report.md -o output/report.docx --reference-doc=template.docx
pandoc output/report.md -o output/report.pdf --pdf-engine=xelatex -V mainfont="Times New Roman" -V fontsize=14pt -V geometry:margin=2cm
```
Конвертация не выполнялась ввиду отсутствия pandoc и LaTeX в среде.
