# Самара: технические задания «по вариативному меню» (2027)

Положено 06.11.2026 (Потаповский и Тольятти) и дополнено 10.11.2026 (Отрадненский дом-интернат). Файлы двух первых извещений не переписывались. Персональных данных жителей нет. Строка подписи на меню Потаповского в текстовую выписку не перенесена; в файле xlsx она остаётся, потому что это исходный файл извещения.

06.11.2026 файлы скачаны с filestore ЕИС. Из среды, где собирался доклад, ЕИС по-прежнему не открывается. 10.11.2026 то же ограничение: прямое соединение с zakupki.gov.ru обрывается (TLS EOF). Файлы Отрадненского получены из публичного filestore по ссылкам карточки агрегатора, каналом с доступом из Российской Федерации, без регистрации и без капчи. Ссылки на filestore сняты со страницы https://tendermedia.ru/lot/show/61650588.

## Почему отдельная папка

Карточки извещений лежат в [`../samara-variativnoe-menu-zakupki/`](../samara-variativnoe-menu-zakupki/README.md) (08–26.10.2026). Там явно записано, что технические задания не прочитаны. Этот комплект — сами файлы извещений, а не ещё одна карточка агрегатора. 06.11.2026 положены два извещения, 10.11.2026 — третье. Ранний слой карточек не переписывается. Файлы Потаповского и Тольятти не изменялись.
