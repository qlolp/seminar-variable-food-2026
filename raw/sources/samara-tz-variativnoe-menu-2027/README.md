Положено 06.11.2026. Файлы скачаны с filestore ЕИС (`zakupki.gov.ru`) в прогоне этого дня. Из среды, где собирался доклад, ЕИС по-прежнему не открывается: соединение с площадкой здесь не устанавливалось. Персональных данных жителей нет. ## Почему отдельная папка

Карточки извещений лежат в [`../samara-variativnoe-menu-zakupki/`](../samara-variativnoe-menu-zakupki/README.md) (08–26.10.2026). Там явно записано, что технические задания не прочитаны. Этот комплект — сами файлы двух извещений, а не ещё одна карточка агрегатора. Ранний слой карточек не переписывается.
