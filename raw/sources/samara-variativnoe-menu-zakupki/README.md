# Самарская область: закупки «приготовления питания по вариативному меню» (2025–2027)

Положено 08.10.2026 ежедневной проверкой по постоянному разрешению автора (07.10.2026); дополнено 13.10.2026 — публичные карточки закупок и сайт учреждения. Персональных данных нет: контактные лица, телефоны и e-mail из снимков удалены; страница сайта учреждения со списком сотрудников не сохранялась (цитаты — в `text.md`).

## Что это

Карточки извещений по 44-ФЗ на агрегаторах закупок, воспроизводящие сведения ЕИС: государственные бюджетные учреждения социального обслуживания Самарской области закупают у стороннего исполнителя услугу, предмет которой назван в самом извещении — «оказание услуг по приготовлению питания **по вариативному меню**». Открытые конкурсы в электронной форме через уполномоченный орган области по организации торгов; единица — койко-день; ОКПД2 56.29.20.190.

- Технические задания, приложения к ним (меню), проекты контрактов — **не прочитаны**. ЕИС (`zakupki.gov.ru`, в том числе прямые ссылки filestore) из среды подготовки недоступна: соединение сбрасывается на TLS (08.10.2026). Агрегаторы открывают файлы только после регистрации или за плату — не обходили.
- Поэтому неизвестно, что заказчик понимает под «вариативным меню» (выбор в момент еды, заказ накануне или варианты цикла), сколько вариантов, как выбирают неговорящие и маломобильные, входят ли продукты в цену койко-дня.
- Карточка Потаповского дома-интерната в выдаче 08.10.2026 не открылась — по-прежнему вне перечня.
- Карточка Самарского областного геронтологического центра (№ 0142200001326016552) не открылась 08.10.2026; **открыта 13.10.2026** — внесена в `text.md` и `snapshots/gerontologicheskij_centr.txt`.
