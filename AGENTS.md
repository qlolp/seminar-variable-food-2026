## Три слоя (не смешивать)

| Слой | Кто пишет | Правило |
| --- | --- | --- |
| `raw/` | человек (агент копирует по инструкции ingest) | **Иммутабельно.** Читать. Цитировать путь. **Никогда не править** содержимое источников. |
| `wiki/` | агент | Владеет слоем. Короткие страницы, одна тема, живые ссылки, честные пробелы. |
| `AGENTS.md` | человек + агент (осторожно) | Конвенции. Менять только если конвенция реально сломалась. |

Человек курирует источники и задаёт вопросы. Агент резюмирует, связывает, ведёт `index.md` и `log.md`.

Голос контентных страниц: **директор — директорам.** Автор корпуса — Чистяков Е. В., ДСО «Серафимовский» (223-ФЗ). Со-модератор сессии 26.08.2026 — Нурбаев Т. А., ДСО «Тесовый берег» (44-ФЗ). Кухни и законы не путать. Не писать «агент подготовил материалы» и не обращаться к Евгению как к внешнему заказчику.

```

  assets/                         # локальные картинки; агент не выдумывает файлы
wiki/
  index.md                        # каталог; агент читает ПЕРВЫМ при query
  log.md                          # только append
  overview.md                     # живой синтез темы
  gaps.md                         # пробелы, противоречия, что класть дальше
  concepts/                       # понятия (одна тема = одна страница)

```

Пути wiki — ASCII (`wiki/concepts/disfagiya.md`). Русские имена файлов допустимы в `raw/` (PDF для участников).

## Типы страниц `wiki/`

Frontmatter обязателен:

```yaml
---
title: Короткое русское имя
type: concept | entity | source | synthesis | index | log | gap | query
tags: [вариативность, санпин]
sources:
  - raw/sources/ne-prosto-nakormit/doklad/главы/08_lestnica.md
updated: 2026-09-02
confidence: high | medium | low
---
```

- `title` — как в каталоге.
- `type` — ровно одно значение из списка.
- `tags` — 2–8 коротких меток, латиница или кириллица.
- `sources` — пути внутри `raw/` (не URL вместо пути, если файл есть в репо).
- `updated` — дата правки страницы (ISO).
- `confidence`: `high` = прямая цитата проверенного источника с датой; `medium` = устойчивое толкование доклада; `low` = пробел, вторичка, или соседний репо без ingest.

Тело страницы:

1. Определение в 1–4 предложениях.
2. Факты со ссылкой на `raw/...` (путь + якорь/раздел, если есть).
3. Связи: wikilinks на соседние страницы.
4. Противоречия и пробелы — явно, не «сглаживать».
5. Не дублировать том доклада. Короткая страница > длинная.

Запрещено на wiki-странице: выдуманные цифры, «как известно», приказы «для всех регионов», медицинские назначения от имени кухни.

## Домен: словари, которые нельзя смешивать

1. **Цикличное меню** ≠ **вариативное меню** ≠ **таблица замен** ≠ **персонализация (диета/текстура)**. Определение — глава 8.1 доклада.
2. **Модели М0–М5** (технология раздачи, гл. 8.2) и **ступени участия 0–5** (мера контроля жителя, гл. 8.6) — **разные оси**. Форма ступени в семинарском пакете измеряет модели М0–М5, не ступени участия. Не склеивать нумерацию.
3. **223-ФЗ (Серафимовский)** и **44-ФЗ (Тесовый берег)** — разные контуры закупок.
4. **ПНИ** и **ДСО** — разный правовой акцент (гл. 17.14). Ст. 43 закона № 3185-1 — статус проживающих с психическими расстройствами, не «опекун учитывает мнение» (это ст. 29 ГК и 48-ФЗ).
5. **СанПиН 3590-20** действовал на семинаре 25–27.08.2026. **СанПиН 4282-26** — с 01.09.2026, переходного периода нет. Журналы августа не переписывать.
6. **Приказ № 124 от 10.03.2026** — локальный акт Серафимовского, не федеральная норма.
7. Классы утверждений доклада (гл. 4.0a, 41): норма / толкование / рекомендация / проект локальной формы. Не повышать класс.
8. Клинику кухня не назначает. Текстуры, «диабетический стол», отказ, зонд — врач.
9. Учебные кейсы 1–22 — типовые механизмы, не хроника конкретного дома.

Маркеры сырья литературного md: `{{S…}}` российские источники, `{{M-…}}` клиника, `{{I-…}}` международное. Сохранять класс, не «переводить в факт».

Даты корпуса «Не просто накормить»: данные **23.07.2026**, правовая сверка **19–21.08.2026**. После этих дат — `confidence: low`, пока не ingest свежей нормы.

## Операции

### Ingest (новый файл в `raw/`)

1. Человек кладёт файл в `raw/sources/...` (агент не переписывает уже лежащее).
2. Прочитать источник. Не править `raw/`.
3. Создать или обновить `wiki/sources/<slug>.md`.
4. Обновить затронутые `concepts/` и `entities/` (часто 8–15 страниц). Новую страницу — только если темы ещё нет.
5. Зафиксировать противоречия на страницах и в `wiki/gaps.md`.
6. Переписать затронутые абзацы `wiki/overview.md` (синтез, не оглавление).
7. Обновить `wiki/index.md` (ссылка + одна строка).
8. Append в `wiki/log.md`:

```markdown
## [YYYY-MM-DD] ingest | Краткое имя источника
```

9. Если источник — соседний репо: сначала stub README в `raw/sources/related/<name>/`, потом ingest. Не выдумывать главы, которых нет в снимке.

### Query (вопрос к wiki)

1. Прочитать `wiki/index.md`.
2. Открыть 3–8 релевантных страниц. При дыре — читать указанный `raw/`, не фантазировать.
3. Ответ с цитатами путей `raw/` и wiki-страниц.
4. Сильный ответ — сохранить в `wiki/queries/` и добавить в index + log:

```markdown
## [YYYY-MM-DD] query | Вопрос в пяти словах
```

### Lint (здоровье wiki)

После ingest или когда ссылки «поплыли»:

1. Каждая страница из index существует.
2. Нет сирот (страница есть, на неё никто не ссылается) — кроме свежих query.
3. Нет понятий в тексте без страницы, если понятие уже в каталоге под другим slug.
4. Frontmatter валиден; `sources` указывают на существующие файлы.
5. Противоречия не затёрты.
6. `raw/` не изменён в том же коммите, что «косметика wiki», без явной задачи ingest/copy.
7. Append:

```markdown
## [YYYY-MM-DD] lint | Что проверяли
```

Локальная проверка: `python3 .github/check_handout.py`.

## Чего агент не делает

- Не редактирует `raw/**`, кроме явного «скопируй snapshot / поправь stub README».
- Не сливает PR, не force-push, не выдумывает судебную статистику по вариативности.
- Не назначает диеты, текстуры, препараты.
- Не выдаёт шаблоны приложений за норматив.
- Не обещает, что вариативность бесплатна или доказана РКИ в психиатрии (пробел гл. 27 / 41.3).
