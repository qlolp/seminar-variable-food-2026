# Иллюстрации второй редакции

Схемы и диаграммы доклада. Каждая иллюстрация — отдельный SVG-файл, написанный вручную (без растровых вставок и внешних ссылок), вставляется в главу HTML-блоком:

```html
<figure class="fig">
<img src="иллюстрации/08_lestnica-modeley.svg" alt="Краткое описание для незрячего читателя">
<figcaption>Лестница моделей выбора: от М0 до М5 (раздел 8.2){{S015}}</figcaption>
</figure>
```

Пустая строка до и после блока обязательна. Номер «Рисунок N.» ставит сборка (CSS-счётчик), в подписи номер не пишется. Маркеры источников `{{…}}` в подписи допустимы и превращаются в ссылки при сборке.

## Единый стиль

- `viewBox` шириной **680**, высота по содержанию; без `width`/`height` в пикселях (масштабируется на ширину колонки, ≈170 мм).
- Шрифт: `font-family="Inter, 'DejaVu Sans', sans-serif"`; основной текст 13–14, подписи 11–12, заголовок внутри рисунка не нужен — он в `figcaption`.
- Палитра (печать в цвете и в оттенках серого остаётся читаемой):

| Токен | Цвет | Для чего |
|---|---|---|
| ink | `#1d2a2e` | текст, контуры |
| teal | `#1f6f6a` | основной смысловой цвет, «делаем» |
| teal-light | `#d6ebe8` | заливка блоков |
| ochre | `#c08a2d` | акцент, внимание, «проверить» |
| ochre-light | `#f5e9d2` | заливка акцентных блоков |
| brick | `#a63d32` | клиника, риск, «только врач» |
| brick-light | `#f4dcd8` | заливка клинических блоков |
| slate | `#5b6b73` | вторичный текст, оси |
| line | `#c9d1d4` | сетка, разделители |

- Скругление блоков `rx="6"`, толщина линий 1.5, стрелки — один `marker` на файл.
- Никаких чисел, которых нет в тексте главы с маркером источника. Диаграмма с данными подписывает источник в `figcaption`.
- Клинические шаги (дисфагия, удушье, отказ от еды, лекарства) всегда помечены цветом brick и формулой «решает врач»: клинику кухня не назначает.
