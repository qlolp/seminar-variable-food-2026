## Визуальный QA (25.08.2026)

Метод: Chrome headless, каждый слайд PNG при 1920×1080 и 1280×720; чтение изображений; клик/клавиши в HTML; PDF через печать 16:9 (26 страниц).

**Найдено и исправлено**
- Playfair с CDN без кириллицы → встроенные Noto Serif Display + Inter (woff2).
- Холст 1280, текст мелкий → холст 1920×1080 с масштабом во вьюпорт.
- Высокие карточки с текстом «прилипшим» к верху (тезис, контур, красные линии) → вертикальное центрирование.
- Слабый контраст терракота на беже → `#8C351C` для меток.
- Круг на заключении наезжал на футер → сдвинут вниз, футер z-index 2, светлее на тёмном.
- R2 — две простыни текста → нумерованный список 1–10.
- Лента СанПиН без подписи порога → маркер «01.09».
- Пустая 27-я страница PDF → `break-after: auto` на последнем слайде.
- Печать: сброс `transform`/`left`/`top` от JS-масштаба.

**Остаточный риск**
- PDF Chrome даёт 1440×810 pt (16:9), не 1920 px; на проекторе HTML предпочтительнее PDF.
- Футер 20 px на 1920 ≈ 13 px на 1280 — читается в зале только как служебная строка.
- Figma MCP в среде без auth — колода не в Figma Slides.
- Зал без локальных файлов `fonts/` рядом с HTML сломает набор; CDN нет нарочно.
