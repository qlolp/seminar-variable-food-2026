# Шрифты колоды (офлайн)

Встроены в `03_prezentaciya.html` через `@font-face`, без CDN.

| Файл | Семья | Лицензия |
|---|---|---|
| `NotoSerifDisplay-*.woff2` | [Noto Serif Display](https://fonts.google.com/noto/specimen/Noto+Serif+Display) | SIL OFL 1.1 |
| `Inter-*.woff2` | [Inter](https://rsms.me/inter/) | SIL OFL 1.1 |

Оба набора содержат кириллицу. Playfair Display (Google Fonts без `subset=cyrillic`) на проекторе даёт «тофу» в заголовках — поэтому не используется.
