# Форма базового замера (день 7 фазы 1)

**Документ:** методический инструмент для старшей смены / завпроизводства.
**Версия:** 22.08.2026.
**Назначение:** заполняется на 7-й день ФАЗЫ 1 пилота, до любых изменений в меню.
**Аудитория:** старшая смены пищеблока, завпроизводства, старшая медсестра, врач (для медицинской части).

---

## Часть А. Паспорт замера

| Поле | Значение |
|---|---|
| Учреждение | СПб ГАСУСОН «ДСО „Серафимовский"» / [ваше] |
| Отделение | [номер / название] |
| Дата начала замера | ДД.ММ.ГГГГ |
| Ответственный за заполнение | ФИО, должность |
| Контролирующий | ФИО, должность |

---

## Часть Б. Контингент отделения (5 чисел)

Заполняется **зав. отделением + врачом**. Сверяется с листом жителей.

| № | Показатель | Число | Источник | Комментарий |
|---|---|---|---|---|
| Б1 | Всего жителей в отделении | | Лист жителей | |
| Б2 | Из них едят самостоятельно | | Наблюдение | Стабильные, не нуждаются в помощи |
| Б3 | Из них едят с помощью (нуждаются в кормлении) | | Наблюдение | Нужна норма 1:2 (ориентир) |
| Б4 | Из них неговорящие / малоговорящие | | Наблюдение | Выбор через показ, не вопрос |
| Б5 | Из них в группе дисфагического риска (6 признаков раздела 10.3) | | Врач | Формируется в первые 10 дней |
| Б6 | Из них на весогенных препаратах (M-таблица 11) | | Врач | Клозапин, оланзапин и др. |

**Контрольный вопрос:** если зав. отделением не может назвать число из головы — это первая находка аудита, важнее самого числа.

## Часть В. Тарелочные остатки (7 дней × 3 приёма = 21 замер)

**Метод:** перед подачей взвесить 3 средние порции (одного блюда). После возврата — взвесить остатки. Записать разницу. Среднее = (сумма остатков) / (число жителей в зале этого приёма).

| День | Приём | Блюдо | Порция до (г) | Остаток (г) | Остаток (%) | Число жителей в зале | Темп раздачи (мин) | Примечания |
|---|---|---|---|---|---|---|---|---|
| Пн | Завтрак | Каша | 250 | 80 | 32 | 22 | 18 | |
| Пн | Обед | Борщ | 300 | 65 | 22 | 22 | 22 | |
| Пн | Ужин | Каша | 250 | 100 | 40 | 22 | 15 | Житель X. отказался |
| Вт | Завтрак | ... | | | | | | |

**Средние за неделю (заполняется в конце):**

| Приём | Средний остаток (%) | Минимум (%) | Максимум (%) | Число «аутсайдеров» (блюда с >40 % остатка) |
|---|---|---|---|---|
| Завтрак | | | | |
| Обед | | | | |
| Ужин | | | | |

**Аутсайдеры** — это блюда, у которых средний остаток >40 %. Это кандидаты на замену парами эквивалентов в ФАЗЕ 2.

## Часть Г. Кухонные отходы (7 дней)

**Метод:** в конце смены взвесить ёмкость с пищевыми отходами (без тарелочных остатков). Записать общую массу.

| День | Масса отходов (кг) | Число жителей | г/чел./день | Примечания (источник отходов) |
|---|---|---|---|---|
| Пн | | | | |
| Вт | | | | |
| ... | | | | |
| Среднее | | | | |

**Целевой диапазон после пилота:** 30–80 г/чел./день (снижение относительно базового замера).

## Часть Д. Ночной интервал (7 дней)

**Метод:** в журнале смены записывать время ужина и время завтрака следующего дня.

| День | Время ужина | Время завтрака (след. день) | Интервал (ч) | Примечания |
|---|---|---|---|---|
| Пн | 19:00 | 08:30 | 13:30 | |
| Вт | 19:10 | 08:30 | 13:20 | |
| ... | | | | |
| Среднее | | | | |

**Целевой показатель пилота:** ≤13 часов.
**Международные ориентиры:** Швеция Livsmedelsverket ≤11 ч; США 42 CFR §483.60 (CMS F-Tag 803) — 14 ч верхняя граница.

## Часть Ж. Выводы базового замера

Заполняется завпроизводства + старшая медсестра + врач.

| Вопрос | Ответ |
|---|---|
| Какой приём даёт наибольший остаток? | |
| Какие блюда — аутсайдеры? | |
| Какие жители едят меньше других? | |
| Есть ли проблемы с текстурами? | |
| Есть ли ночные интервалы >13 ч? | |
| Есть ли признаки обезвоживания? | |
| Какие риски требуют немедленных действий? | |
| Какие пары эквивалентов сформировать в ФАЗЕ 2? | |

**Подписи:** старшая смены, завпроизводства, врач, директор (утверждение).

## Часть З. Сырьевая строка

**Формула:** Расходы на продукты за последний полный месяц ÷ число жителей ÷ число дней.

| Поле | Значение |
|---|---|
| Расходы на продукты за последний полный месяц (руб.) | |
| Число жителей (чел.) | |
| Число дней | |
| Сырьевая строка (руб./чел./день) | |
| Сравнение с региональной нормой (если есть) | |

**Зачем:** это базовая цифра для всех финансовых аргументов перед учредителем. Без неё — «мы не знаем, сколько стоит еда».
