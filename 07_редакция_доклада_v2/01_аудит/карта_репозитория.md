## 6. Где противоречия

1. **Нумерация версий PDF в README vs CHANGELOG:** README указывает «официальный 302 стр.» (сборка 21.08 pre-session freeze), CHANGELOG для v1.4 называет «официальный 257 / журнальный 263 / красивый 245 / claude 245» (сборка после v1.4). Это **нормальный рабочий разнобой** при ежедневной пересборке, не дефект.
2. **Источник S004 «Если быть точным»** в реестре указан с датой 23.07.2026, в самом докладе для «74 %» — ссылка «публикация 09.04.2026». Это **разные даты**: первая — дата верификации агентом, вторая — дата оригинальной публикации. Нужно явно разделить в новой редакции.
3. **M-crwg «клозапин 76,3 %»** (прибавка ≥7 % веса за 38 нед.) в реестре помечен как «BJPsych Open, January 2023, DOI 10.1192/bjo.2022.619», и тут же оговорка «Campforts 2026 — другая статья (семаглутид/метформин)». В самом тексте доклада 76,3 % упоминается в связке с «мета-анализ 100 РКИ» (это **M-pillinger**, Lancet Psychiatry 2020), а 76,3 % — из M-crwg. **Нужна чёткая разводка: 76,3 % — M-crwg, а не Pillinger.**
4. **Сноска M-ebt / S004 дублируется:** «466 ПНИ / 139 500 / 74 %» в одном месте идёт как S004 (российский правовой реестр), в другом — как M-ebt (клинические источники). Это **источник один и тот же** — проект «Если быть точным», апрель 2026. В новой редакции — один ID, не два.
