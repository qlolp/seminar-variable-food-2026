# Сборка редакции v2 — DOCX и PDF

**Дата:** 22.08.2026.
**Назначение:** сборка всех материалов редакции v2 в форматы DOCX (для редактирования) и PDF (для печати и распространения).

## Что в этой директории

- `dist/` — собранные DOCX и PDF (32 файла, 6.4 МБ).
- `build.py` — сборка DOCX через pandoc.
- `build_pdf.py` — сборка PDF через Chrome/Edge headless.
- `style.css` — стиль оформления (Playfair Display + PT Sans + терракот).
- `html/` — промежуточные HTML (не публикуются).
- `docx/` — промежуточные DOCX (если сборка PDF не запускалась).
- `pdf/` — промежуточные PDF (если сборка DOCX не запускалась).
- `reference.docx` — шаблон стилей DOCX.

## Как пересобрать

```bash
# DOCX (требует pandoc)
cd 07_редакция_доклада_v2/_build
python build.py docx

# PDF (требует pandoc + Chrome/Edge; weasyprint не сработал на Windows из-за отсутствия libgobject-2.0-0.dll)
python build_pdf.py
```

## Ограничения сборки

- **Шрифты.** Используются Playfair Display и PT Sans, доступные в системе. На Windows без этих шрифтов — fallback на Times New Roman и Arial.
- **Таблицы.** pandoc конвертирует GFM-таблицы корректно, но сложные таблицы с merged cells могут поехать.
- **Кириллица.** UTF-8 throughout; работает корректно.
- **Изображения.** В текущей версии нет изображений; для будущих версий с диаграммами — добавить пути.
- **Шапка/колонтитул.** PDF имеет номер страницы внизу; в DOCX — стандартные.
- **Поля.** 2 см × 1.8 см (A4); для некоторых учреждений могут потребоваться поля под переплёт 3 см.

## Что в DOCX, чего нет в Markdown

- TOC (оглавление с гиперссылками) — до 3-го уровня.
- Метаданные: title, author, date, lang.
- Стили заголовков H1–H4 по reference.docx.
- Автоматические списки, цитаты, таблицы.

## Что в PDF, чего нет в DOCX

- Закладки (bookmarks) для навигации.
- Номера страниц в нижнем колонтитуле.
- Шрифты встроены.
- Единообразное форматирование (Playfair Display + PT Sans + терракотовый акцент).
- A4, поля 2 см × 1.8 см.
