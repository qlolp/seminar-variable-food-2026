## Сборка из исходников

Исходники (правим их): `проект/chapters/*.md`, `проект/cases/*.md`, `проект/appendices/*.md`, реестры `проект/*.xlsx` и генератор слайдов `02_презентация/презентация_v5_21_слайд/build_v5.py`. Всё в `проект/output/` и готовые PDF/HTML — сгенерированные артефакты, их не редактируют вручную.

Зависимости: Python 3, [pandoc](https://pandoc.org/) (Markdown → HTML), [WeasyPrint](https://weasyprint.org/) (HTML → PDF) с нативными библиотеками (pango/cairo/gdk-pixbuf) и `pdfunite` из poppler-utils. Python-пакеты закреплены в `requirements.txt` (`weasyprint`, `pydyf`, `openpyxl`, `pypdf`, `PyYAML`).

Установка окружения (Debian/Ubuntu) — одной командой `bash .cursor/install.sh` (системные пакеты + `pip install -r requirements.txt`).

Сборка:

```bash
# Доклад: 4 PDF в проект/output/ (официальный, журнальный, красивая, стиль claude)
python3 проект/scripts/rebuild_pdfs.py

# Презентация v5: 21 слайд → 02_презентация/Презентация_дискуссия_26_08_v5_стиль_claude.pdf
python3 02_презентация/презентация_v5_21_слайд/build_v5.py --pdf
```

Сборка проверяется в CI (`.github/workflows/build.yml`) на каждый push и pull request.
