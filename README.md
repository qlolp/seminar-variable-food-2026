# Не просто накормить — доклад и семинарский пакет

Материалы семинара «Пространство Новых Идей 2.0» (Санкт-Петербург, 25–27 августа 2026, Минтруд России):
доклад «Не просто накормить: как организовать безопасное, достойное и вариативное питание людей
с психическими нарушениями в домах социального обслуживания» и весь сопутствующий инструментарий.

## Состав репозитория

- **01_доклад/** — доклад: HTML, официальный PDF 284 стр., журнальный PDF 241 стр., красивая версия PDF 214 стр., DOCX
- **02_презентация/** — презентация на 46 слайдов (.pptd; докладчик — Чистяков Е. В.)
- **03_семинарский_пакет/** — 18 инструментов семинара (выступления, чек-листы, аудит, формы)
- **04_приложения_и_реестры/** — реестры источников и контрольные файлы (XLSX, MD)
- **05_раздатка_canva/** — раздаточные листовки A4 (6 шт.)
- **06_викторина_canva/** — материалы викторины (4 шт.)
- **проект/** — рабочая директория: 44 раздела (`chapters/`), 22 кейса (`cases/`), 45 приложений
  (`appendices/`), скрипты сборки (`scripts/`)
- **семинар_пакет_2026.zip** — печатные материалы семинара одним архивом: раздатки,
  викторина и основные реестры (русские имена в UTF-8)
- **ПРОЧТИ_МЕНЯ.md** — навигатор по всему пакету

Дата актуальности данных: 23.07.2026; правовая сверка 17.08.2026.
