# Не просто накормить — доклад и семинарский пакет

Материалы семинара «Пространство Новых Идей 2.0» (Санкт-Петербург, 25–27 августа 2026, Минтруд России):
доклад «Не просто накормить: как организовать безопасное, достойное и вариативное питание людей
с психическими нарушениями в домах социального обслуживания» и весь сопутствующий инструментарий.

## Состав репозитория

- **01_доклад/** — доклад: HTML, официальный PDF 250 стр., журнальный PDF 257 стр., красивая версия PDF 237 стр., DOCX
  - `01_доклад/Не_просто_накормить_доклад_стиль_claude.pdf` — **версия в стиле claude.com** (237 стр.): тёплая слоновая кость, терракотовый акцент, Playfair Display — единая дизайн-система с презентацией v4
  - `01_доклад/дополнения_18.08.2026/` — карточка Q&A на стол спикеру (A4, 3 прогнозируемых вопроса)
- **02_презентация/** — презентации: основная — v4 в стиле claude (38 слайдов), плюс полная слайдовая версия доклада и ранние варианты
  - `02_презентация/Презентация_дискуссия_26_08_v4_стиль_claude.pdf` — **основная презентация** на сессию 26.08 в едином стиле с докладом «стиль claude»: одна мысль на слайд, минимум текста, крупные цифры, современные графики (donut 74 %, slope-chart IDDSI, таймлайн), вопросные слайды для зала
  - `02_презентация/презентация_v4_38_слайдов/` — исходники основной презентации (`slides/*.html`, генератор `build_v4.py`, README)
  - `02_презентация/презентация_v3_36_слайдов/` — предыдущая версия в стилистике программы семинара (синий + Oswald; PDF `Презентация_дискуссия_26_08_v3_36_слайдов.pdf`)
  - `02_презентация/презентация_34_слайда/` — полная слайдовая версия доклада: `03_презентация.pptd` + `pages/` (37 слайдов; редактор презентаций, экспорт в PPTX); PDF — `Презентация_Не_просто_накормить.pdf`
  - `02_презентация/презентация_v2_30слайдов/` — альтернативный вариант (30+ HTML-слайдов, PDF)
  - `02_презентация/дискуссия_шесть_вопросов/` — ранний мини-дек дискуссии (10 слайдов; заменён v3/v4)
  - `02_презентация/дополнения_18.08.2026/` — слайд-выжимка «цепочка права на выбор еды» (16:9, для Q&A)
- **03_семинарский_пакет/** — 18 инструментов семинара (выступления, чек-листы, аудит, формы)
- **04_приложения_и_реестры/** — реестры источников и контрольные файлы (XLSX, MD)
- **05_раздатка_canva/** — раздаточные листовки A4 (6 шт.)
- **06_викторина_canva/** — материалы викторины (4 шт.)
- **проект/** — рабочая директория: 44 раздела (`chapters/`), 22 кейса (`cases/`), 45 приложений
  (`appendices/`), скрипты сборки (`scripts/`)
- **семинар_пакет_2026.zip** — печатные материалы семинара одним архивом: раздатки,
  викторина и основные реестры (русские имена в UTF-8)
- **ПРОЧТИ_МЕНЯ.md** — навигатор по всему пакету

Дата актуальности данных: 23.07.2026; правовая сверка 19.08.2026 (приказ № 124 — S035, раздел 17.12). Единый стиль claude.com для доклада и презентации v4 — 20.08.2026; журнал правок — `04_приложения_и_реестры/STATUS.md`.
