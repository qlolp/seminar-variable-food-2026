## Сборка из исходников

Исходники (правим их): `проект/chapters/*.md`, `проект/cases/*.md`, `проект/appendices/*.md`, реестры `проект/*.xlsx` и генератор колоды зала `02_презентация/презентация_v6/build/build_v6.py`. Всё в `проект/output/` и готовые PDF/HTML — сгенерированные артефакты, их не редактируют вручную.

Зависимости: Python 3, [pandoc](https://pandoc.org/) (Markdown → HTML), [WeasyPrint](https://weasyprint.org/) (HTML → PDF) с нативными библиотеками (pango/cairo/gdk-pixbuf) и `pdfunite` из poppler-utils. Python-пакеты закреплены в `requirements.txt` (`weasyprint`, `pydyf`, `openpyxl`, `pypdf`, `PyYAML`).

Установка окружения (Debian/Ubuntu) — одной командой `bash .cursor/install.sh` (системные пакеты + `pip install -r requirements.txt`).

Сборка:

```bash
# Колода зала v6 (PPTX, 31 слайд). PYTHONPATH не задавать.
# python-pptx: /usr/bin/python3 (site-packages пользователя) либо pip install python-pptx
/usr/bin/python3 02_презентация/презентация_v6/build/build_v6.py

# PDF колоды зала v6 (WeasyPrint; LibreOffice CLI может отсутствовать)
PATH=/opt/homebrew/bin:$PATH python3 02_презентация/презентация_v6/build/build_v6_pdf.py

# Памятка на стол
PATH=/opt/homebrew/bin:$PATH weasyprint \
  03_семинарский_пакет/памятка_на_стол.html \
  03_семинарский_пакет/Памятка_что_унести_в_регион.pdf

# Руководство (4 PDF в проект/output/)
PATH=/opt/homebrew/bin:$PATH python3 проект/scripts/rebuild_pdfs.py

# Архивный WeasyPrint-дек v5 (не колода зала)
PATH=/opt/homebrew/bin:$PATH python3 02_презентация/презентация_v5_21_слайд/build_v5.py --pdf
```

Сборка проверяется в CI (`.github/workflows/build.yml`) на каждый push и pull request.
