# Вариативное меню — LLM-wiki

Это **LLM-wiki по вариативному меню / вариативному питанию** в стационарных организациях социального обслуживания (ПНИ, ДСО). Паттерн — [Karpathy LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): сырьё в `raw/`, связанный markdown в `wiki/`, правила в `AGENTS.md`.

**Агентам:** читай [`AGENTS.md`](AGENTS.md) и [`wiki/index.md`](wiki/index.md). `CLAUDE.md` указывает туда же. Не начинай с PDF.

Я — **Чистяков Евгений Владимирович**, директор СПб ГАСУСОН «ДСО „Серафимовский“» (223-ФЗ). Со-модератор сессии 26.08.2026 — **Тимур Нурбаев**, директор СПб ГБСУСОН «ДСО „Тесовый берег“» (44-ФЗ). Семинар Минтруда «Пространство Новых Идей 2.0», Санкт-Петербург, 25–27 августа 2026.

Wiki собирает доклад **«Не просто накормить»**, семинарский пакет и (по мере ingest) соседние доклады. Человек кладёт источники; агент ведёт страницы, связи и пробелы.

## Как спрашивать агента

Примеры: «где Серафимовский на лестнице М0–М5», «что ответить проверяющему», «СанПиН с 1 сентября», «почему две лестницы 0–5». Агент идёт в index, затем в страницы, затем в `raw/`. Хороший ответ можно сохранить в `wiki/queries/`.
