# Вариативное меню — LLM-wiki

Это **wiki для агента** по вариативному меню в стационарных организациях социального обслуживания (ПНИ, ДСО). Не витрина семинара и не архив раздатки.

Паттерн — [Karpathy LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): иммутабельное сырьё в `raw/`, связанные короткие страницы в `wiki/`, закон репозитория в [`AGENTS.md`](AGENTS.md).

**Агентам:** сначала [`AGENTS.md`](AGENTS.md), затем [`wiki/index.md`](wiki/index.md). `CLAUDE.md` указывает туда же. Не начинать с `raw/` и не искать PDF «для участников».

## Как спрашивать агента

Примеры: «где Серафимовский на лестнице М0–М5», «что ответить проверяющему», «СанПиН с 1 сентября», «почему две лестницы 0–5». Агент идёт в index, затем в страницы, затем в `raw/`, если в wiki дыра. Хороший ответ можно сохранить в `wiki/queries/`.

Новый источник — не вопрос, а ingest: «ingest `raw/sources/<slug>`» (шаги в [`HOW_TO_ADD.md`](HOW_TO_ADD.md)).

Проверка здоровья wiki: `python3 .github/check_wiki.py`.

## Что лежит в сырье (не раздатка)

Канон первого ingest — литературная редакция «Не просто накормить»: markdown (assembled + главы / кейсы / приложения) и один справочный PDF той же редакции. Рядом — markdown-бланки пакета (чеклисты, возражения, форма ступени): это рабочие тексты, не макеты печати. Соседние репо — stubs и лёгкий снимок в `raw/sources/related/`.
