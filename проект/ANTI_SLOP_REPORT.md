# ANTI_SLOP_REPORT.md — отчёт о соответствии антислоп-требованиям ТЗ

Дата: 26.07.2026. Документ: «Не просто накормить…» (версия для семинара «Пространство Новых Идей 2.0»).

## 1. Правило «каждая цифра имеет источник»

**Исполнено.** Все фактические утверждения с цифрами снабжены маркерами {{Sxxx}} / {{M-key}} / {{I-key}} в исходных файлах; при сборке маркеры преобразованы в сквозные сноски (85 уникальных источников, 563 точки цитирования в тексте; в DOCX — 86 концевых сносок и 478 перекрёстных ссылок). Контроль: CLAIM_SOURCE_MATRIX.xlsx (558 контекстов-строк), три реестра с URL и датами проверки.

## 2. Правило «данных нет»

**Исполнено.** Прямые признания отсутствия данных зафиксированы в тексте: нет РКИ вариативного меню в психиатрии (раздел 27); нет репрезентативной статистики вариативного питания в РФ (разделы 25.6, 41.3); нет судебной практики именно по вариативному меню (разделы 33.2, 41.3); нет публичных данных о сырьевой строке российских СОСО (раздел 39.4); статус вторичной аналитики по статистике ПНИ помечен везде (разделы 16.6, 23, 41.2).

## 3. Запрет суперлативов без систематического поиска

**Исполнено.** Из ранних версий исключены: «единственный публичный пример» (опровергнуто при верификации — найдены 3 практики ПНИ + региональная модель + ДДСОЛ), все превосходные оценки без оговорок. Оставшиеся оценочные суждения помечены как интерпретации.

## 4. Запрет выдуманной экономии

**Исполнено.** Формула «вариативность почти бесплатна» удалена из всех разделов; вместо неё — честная рамка стоимости (раздел 29): три стоимости, иллюстративные расчёты с пометкой «иллюстративный расчёт», обязательный 7-дневный замер до любых экономических утверждений, 5 моделей с диапазонами цены.

## 5. Маркировка «факт / интерпретация / рекомендация / иллюстративный расчёт»

**Исполнено.** В тексте используются явные маркеры: «толкование», «рекомендация», «иллюстративный расчёт (не замер)», «оценка по типовым распорядкам», «модельная оценка». Все 20+ фигур снабжены блоками «исходные данные / источник / год / метод / ограничения»; фигуры с модельными данными (12, 13, рис. 24 о ночном интервале РФ) помечены как иллюстративные.

## 6. Собирательные кейсы маркированы

**Исполнено.** Все 22 кейса открываются единым дисклеймером «Учебный кейс, составленный для анализа»; сцена раздела 5 маркирована как собирательная (раздел 5.4 объясняет причину приёма).

## 7. Дисклеймер приложений

**Исполнено.** Единый дисклеймер «Проект локальной формы. Не является нормативно установленным документом. Требует адаптации…» приведён в шапке части III и на каждом из 36 шаблонов.

## 8. Исключение неподтверждённых источников

**Исполнено.** Приказ 940н (фигурировал в ранних материалах) не подтверждён при верификации — исключён из реестра и текста с записью в журнале аудита (AUDIT_OLD_REPORTS.md, этап 6). Статус форм по 52н дан с оговоркой о поэтапном переходе и рекомендацией подтверждать у учредителя.
