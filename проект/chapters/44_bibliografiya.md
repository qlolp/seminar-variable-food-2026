# 44. Библиография и источники

Полный перечень источников доклада формируется автоматически из трёх контрольных реестров при сборке и приводится далее единым списком со сквозной нумерацией сносок (номер в тексте = номер в списке):

- **Нормативные акты, судебная и правоприменительная практика, российские публичные практики** — канонический реестр `проект/SOURCE_REGISTRY.xlsx` (**34 записи**, маркеры S001–S035 без S026, даты проверки — июль–август 2026 года). Часть позиций основана на внутренних документах или вторичных источниках; ограничения — в полях «URL», «Уровень уверенности», «Примечание».
- **Клинические источники** — реестр MEDICAL_EVIDENCE.xlsx (48 записей: систематические обзоры, мета-анализы, руководства IDDSI и профессиональных обществ, клинические случаи);
- **Международные нормы и практики** — реестр INTERNATIONAL_PRACTICES.xlsx (44 записи: законы, подзаконные акты, стандарты, отчёты аудиторов девяти систем).

В тексте доклада каждый источник приводится в сноске в месте первого упоминания; повторные ссылки указывают на номер сноски. Список ниже дублирует сноски для удобства печатного чтения: **номер пункта = номер сноски**, в квадратных скобках — ID реестра (S… / M-… / I-…). Копия реестров для раздачи лежит в `04_приложения_и_реестры/`; при расхождении верен файл в `проект/`.
