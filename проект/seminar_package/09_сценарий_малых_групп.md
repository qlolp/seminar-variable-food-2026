# Сценарий обсуждения в малых группах (45 минут)

**Формат:** группы по 8–10 человек, желательно смешанные (директор + заведующая отделением + диетсестра + врач, из разных регионов). В каждой группе назначаются: ведущий (выбирает сама группа, не по должности), секретарь (пишет на флипчарте), докладчик (представляет итог залу).

**Материалы на группу:** флипчарт, маркеры, один распечатанный кейс (из 22 учебных кейсов доклада — разным группам разные кейсы), лист самоопределения ступени (элемент 12 пакета), лист экспресс-аудита (элемент 11).

---

## Блок 1. Открытие и разогрев (0:00–5:00)

Ведущий предлагает каждому закончить фразу по своему учреждению одним предложением:

> «Вчера в нашем доме житель выбирал еду в момент, когда…»

Если ответить нечего — честная формулировка: «Вчера в нашем доме житель не выбирал». Это нормальный ответ, а не провал: именно с него начинается работа.

*Задача блока:* каждый проговорил ситуацию вслух, группа услышала разброс исходных позиций.

## Блок 2. Разбор кейса (5:00–20:00)

Группа читает кейс (5 минут, каждый про себя), затем отвечает на три вопроса по очереди, по кругу, без комментариев ведущего:

*Кейс докладчика (по желанию ведущего вместо карточки):* эксперимент ДСО «Серафимовский» (раздел 25.5 доклада; источник — публикация учредителя от 22.07.2025) разбирается по тем же трём вопросам плюс четвёртый: «что сделать с тягой к популярным, но неполезным продуктам — кроме запрета?» (подсказка докладчика: пары эквивалентов и пересчёт пропорций, разделы 19 и 21). Плюс кейса — он реальный и оплаченный ценой; минус — в нём нет «провала», поэтому для тренировки реакции на аварию лучше учебные карточки.

1. **Что здесь произошло на самом деле?** — отделить факты от оценок. (Типовая ловушка: группа начинает с «виноват диетсестра» — ведущий возвращает к фактам: «что именно записано в журнале?»)
2. **На какой ступени вариативности стоит это учреждение** — по лестнице из доклада (ступени 0–5), с обоснованием одним предложением.
3. **Одно действие, которое учреждение из кейса может сделать в ближайшие две недели без новых денег** — конкретное, с ответственным и сроком.

Секретарь фиксирует на флипчарте: ступень (большая цифра) + одно действие.

*Правило ведущего:* не допускать обсуждения «почему у нас так не получится». Вопрос группы — «что сделать», а не «почему нельзя». Возражения директоров разбираются отдельно (элемент 14 пакета) — там они все уже собраны, здесь время на них не тратится.

## Блок 3. Перенос на себя: ступень своего учреждения (20:00–33:00)

Каждый участник заполняет лист самоопределения ступени (элемент 12) применительно к своему учреждению — 5 минут индивидуально.

Затем пары «сосед по столу» сверяют ответы: партнёр задаёт три контрольных вопроса из листа («покажите вчерашний журнал», «был ли второй вариант физически на линии», «кто вчера выбрал не то, что принесли бы по умолчанию»). Если ответы расходятся с заявленной ступенью — пара фиксирует расхождение и причину.

*Зачем пары:* самооценка завышает ступень почти всегда; вопрос партнёра снижает завышение без конфликта — спрашивает не ведущий семинара, а коллега.

## Блок 4. Одно решение в понедельник (33:00–40:00)

Каждый участник выбирает из чек-листа «Что директор может сделать в понедельник» (элемент 5 пакета) **один** пункт и формулирует его для своего учреждения: что, кто, когда, чем измерим результат через месяц.

Секретарь записывает решения всех членов группы в общий список.

## Блок 5. Отчёты в зал (40:00–45:00)

Докладчик каждой группы — 60 секунд, строго по форме:

> «Наш кейс — [номер и название]. Ступень учреждения из кейса — [цифра]. Одно действие для него — [формулировка]. В нашей группе учреждения стоят на ступенях [перечисление]. Решения в понедельник: [два-три самых частых].»

Модератор общего зала собирает на общем флипчарте две колонки: «Ступени в зале» и «Решения в понедельник». Этот флипчарт фотографируется и становится частью итогов семинара: зал видит собственную карту исходных позиций — не анонимную статистику организаторов, а свои формулировки.

## Частые сбои сценария и их профилактика

| Сбой | Профилактика |
| --- | --- |
| Группа уходит в обмен жалобами на нормативку | Ведущий возвращает к вопросу «что сделать»; правовые споры откладываются к юристу семинара |
| Один участник говорит 80% времени | Формат «по кругу, одно предложение» в блоках 1–2; ведущий прерывает: «ваша позиция записана, дальше по кругу» |
| Все выбирают «лёгкий» пункт чек-листа | Это допустимо: выбранный и выполненный пункт лучше амбициозного и забытого |
| Группа не сходится в оценке ступени кейса | Расхождение фиксируется как результат: «группа разошлась между ступенями 1 и 2» — это само по себе показывает субъективность шкалы без журнала |
| Не хватает времени на отчёты | Сокращается блок 3 (сверка в парах), а не блок 5: отчёты в зал — главный продукт работы |

*Примечание для организаторов:* сценарий не требует специальной подготовки ведущих групп — все инструкции в тексте; достаточно десятиминутного брифинга ведущих перед началом.
