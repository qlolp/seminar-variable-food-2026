## 2. Исключаемые и переписываемые блоки (итог)

**Исключаются полностью:**
1. Любые превосходные степени без систематического поиска («единственное в мире», «самая детальная», «лучшая в мире эмпирическая связка» — последняя из заключения Д3).
2. Утверждение Д3 «честная смета вариативности ≈ 0 руб.» — заменяется финансовыми моделями с иллюстративными расчётами (ТЗ п. 17).
3. Пафосные формулы заключения Д3 («уже не интернат. Это дом») — тон нового доклада спокойный, без рекламы.
4. Непроверенная статистика «466 ПНИ / 139 500 / 74 % недееспособных» из Д3 — до подтверждения первичным источником Минтруда; источник «Если быть точным» — проект ТАСС, уровень D (пресс-аналитика), не официальная статистика (этап 5).

**Переписываются полностью:**
1. Правовой блок — по модели «карта решений» (12 вопросов ТЗ п. 13), а не перечень норм.
2. Ответственность директора — заново, с разграничением составов и без прецедентов «по аналогии» без маркировки.
3. Финансы — заново: 5 моделей, замеры, без выдуманной экономии.
4. Региональный блок — заново на основе PARTICIPANTS_CLEAN.xlsx и проверки ≥15 субъектов.

**Сохраняются (после повторной проверки редакций на этапах 5–9):**
- федеральная правовая рамка Д1 (442-ФЗ, 3185-1, ГК, ЗО, санитарный блок, 44-ФЗ) — ядро было сверено с первоисточниками;
- клиническое ядро Д3 (лекарственно-пищевые взаимодействия, вес, дисфагия, мониторинг) — сверено с первичными исследованиями;
- международные проверяемые нормы Д2 — сверены с первичными текстами (O. Reg. 246/22, 42 CFR §483.60, DGE-QST, Livsmedelsverket, японские доплаты, BDA);
- методические инструменты (пищевой паспорт, триггеры, аудит, план 90 дней) — как проекты локальных форм с обязательной пометкой ТЗ п. 23.

## 3. Численный итог аудита

- Всего разобрано существенных утверждений/блоков: 20 проблемных зон + ~60 атомарных утверждений внутри них.
- Решения: сохранить после повторной проверки — ~40 %; уточнить — ~35 %; переписать полностью — ~20 %; исключить — ~5 %.
- Главный системный дефект старых докладов: уверенные обобщения там, где источник — одиночная новость или отраслевая ассоциация; недостаточная маркировка «норма / интерпретация / рекомендация».
- Главный системный актив: первичные международные нормы и клинические исследования были действительно сверены с первоисточниками — это ядро нового доклада.
