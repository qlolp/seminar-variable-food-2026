# Форма самоопределения ступени вариативности

*Заполняется по фактам вчерашнего дня и текущих документов, а не по представлениям. Принцип: ступень определяется вчерашним днём, а не принятым положением. Если на вопрос нельзя ответить документом или фактом — ответ «нет».*

**Учреждение:** ____________________ **Дата:** ________ **Заполнил:** ____________

---

## Шаг 1. Три контрольных вопроса к фактам

**1. Покажите вчерашний журнал.** Есть ли в нём за вчера хотя бы одна запись о выборе жителя (вариант А/Б, замена по отказу, индивидуальная просьба, исполненная не по умолчанию)?
☐ Да — запись есть &nbsp;&nbsp; ☐ Нет — журнал есть, но выбор не зафиксирован &nbsp;&nbsp; ☐ Журнала нет

**2. Был ли второй вариант вчера физически на линии?** Дошёл ли вариант Б до последнего отделения, или закончился раньше (спросить смену, сверить с журналом срывов)?
☐ Дошёл &nbsp;&nbsp; ☐ Закончился раньше &nbsp;&nbsp; ☐ Второго варианта не было &nbsp;&nbsp; ☐ Не знаю

**3. Кто из жителей вчера выбрал не то, что ему принесли бы по умолчанию?** Назовите хотя бы одного по имени. Если таких нет третью неделю подряд — выбор декоративен, что бы ни говорили бумаги.
☐ Такие жители есть (число: ____) &nbsp;&nbsp; ☐ Таких нет &nbsp;&nbsp; ☐ Не знаю

*Если на все три вопроса ответ отрицательный — дальнейшие шаги не нужны: ваша ступень 0, и это честная стартовая точка.*

## Шаг 2. Определение ступени

Отметьте **наивысшую** строку, по которой выполняются **все** условия строки:

| Ступень | Условия (все сразу) | ✓ |
| --- | --- | :---: |
| **0. Мономеню с учётом отказов** | Выбора нет; отказ от блюда влечёт замену по таблице; остатки разбираются и влияют на меню | |
| **1. Выбор из двух в одной позиции** | Один второй вариант ключевого блюда хотя бы на части приёмов пищи; выбор фиксируется в журнале; вариант Б доходит до последнего отделения | |
| **2. Выбор по всем основным позициям ежедневно** | Два варианта первых, вторых, гарниров, напитков — каждый день; объёмы готовки пересчитываются по статистике выбора | |
| **3. Выбор на линии раздачи** | Житель комплектует тарелку на линии хотя бы по части позиций (салаты, напитки, десерты); санитарный контроль открытых блюд организован | |
| **4. Семейная подача за столом** | Общие блюда на столе, жители накладывают сами хотя бы на части отделений; персонал сопровождает, а не раздаёт | |
| **5. «Своя кухня»** | Жители участвуют в приготовлении (квартира тренинга навыков или аналог) | |

**Итоговая ступень учреждения: ____**

## Шаг 3. Проверка на регресс

Ответьте про квартал, предшествовавший вчерашнему дню:

1. Доля жителей, выбирающих вариант Б, за квартал: ☐ выросла ☐ стабильна ☐ упала ☐ не измеряется
2. Журнал срывов (вариант Б закончился раньше последнего отделения) за квартал: ☐ ведётся, записи есть ☐ ведётся, записей нет ☐ не ведётся
3. Ответственный за вариативность за год: ☐ тот же ☐ сменился, процедура сохранилась ☐ сменился, процедура «упрощена»

*Пустой журнал срывов чаще означает не отсутствие срывов, а прекращение записи — признак регресса, читаемый раньше жалоб.*

## Шаг 4. Один шаг на следующую ступень

Ступени не перепрыгивают. Заполните по своей текущей ступени:

- **Со ступени 0 → 1:** выбранная позиция (например, каша на завтрак), два эквивалентных варианта по таблице замен, журнал заказа, дата старта: ________
- **Со ступени 1 → 2:** какие позиции добавляются к существующей, в какие дни: ____________________
- **Со ступени 2 → 3:** какая буфетная зона и на каком приёме пищи: ____________________
- **Со ступеней 3–5:** план согласуется с учредителем и врачом отдельно (элементы 17–18 пакета)

**Ответственный:** ____________ **Первая проверка результата (дата):** ________
