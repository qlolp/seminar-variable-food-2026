# Интерактивный экспресс-аудит учреждения (10 минут)

*Используется на семинаре вживую: участники проходят аудит по своему учреждению из зала, по памяти о вчерашнем дне. Тот же лист — инструмент первой недели пилота на месте (тогда ответы даются не по памяти, а по факту). Десять пунктов, один бит каждый: «да» = 1, «нет / не знаю» = 0. «Не знаю» честнее, чем «да» — и само по себе диагностично.*

---

## Бланк

**Учреждение:** ____________________ **Дата:** ________ **Заполнил (должность):** ____________

| № | Проверяемый факт | Да | Нет / не знаю |
| --- | --- | :---: | :---: |
| 1 | Вчера хотя бы на одном приёме пищи житель мог выбрать между двумя вариантами хотя бы одного блюда | | |
| 2 | Этот выбор вчера зафиксирован документально (журнал заказа или иная форма) | | |
| 3 | Второй вариант вчера физически дошёл до последнего отделения (не закончился на первом) | | |
| 4 | Отказ жителя от блюда вчера повлёк замену, а не пустую тарелку | | |
| 5 | Кто-то из руководства ел еду жителей за последний месяц — на столе жителей, а не в кухне | | |
| 6 | Вчерашний интервал между последним приёмом пищи вчера и первым сегодня — не более 13 часов (знаю точно) | | |
| 7 | Остатки на тарелках вчера кто-то посмотрел и хотя бы мысленно отнёс на счёт конкретного блюда | | |
| 8 | Журнал температурного контроля вчера заполнен — и температура на последнем столе известна | | |
| 9 | Есть список жителей, которым еда доставляет трудность (дисфагия, тремор, односторонний парез, седация), — и он совпадает у врача, диетсестры и отделения | | |
| 10 | За последний квартал меню менялось хотя бы раз по итогам мнения жителей (совет, опрос, разбор отказов) | | |

**Итого баллов (сумма «да»): ____ / 10**

## Шкала прочтения

| Баллы | Что это значит | Первый шаг |
| --- | --- | --- |
| 0–3 | Ступень 0 или ниже: выбор не существует или невидим для документов | Начать с журнала отказов и замера ночного интервала — оба бесплатны |
| 4–6 | Ступень 0–1: элементы есть, системы нет | Выбрать одну позицию (завтрак, каша А/Б) и довести её до документированного выбора |
| 7–8 | Ступень 1–2: выбор реален, но уязвим (держится на людях, а не на процедурах) | Закрепить приказом, ввести квартальную панель чисел |
| 9–10 | Ступень 2 и выше: система работает | Проверить её пятью критериями реального выбора (раздел 22 доклада) и подумать о ступени 3 точечно |

*Предупреждение:* аудит по памяти завышает результат на 1–2 балла. Повторите его на месте, с журналами в руках — расхождение между двумя версиями покажет, что в учреждении живёт в представлениях, а что в документах.

## Как проводить на семинаре (инструкция модератору)

1. **Минута 0–1.** Раздать бланки. Объявить правило: отвечаем про **вчерашний день**, а не про «как у нас вообще».
2. **Минуты 1–7.** Участники заполняют молча, индивидуально. Консультации с соседом запрещены — аудит по памяти ценен именно честностью.
3. **Минуты 7–9.** Участники считают баллы и поднимают руки по шкале: «у кого 0–3? 4–6? 7–8? 9–10?». Модератор фиксирует распределение на доске — это карта зала, которую никто не готовил заранее.
4. **Минута 9–10.** Один вопрос залу: «Какой из десяти пунктов оказался для вас самым неудобным — не по ответу, а по вопросу?» Два-три голоса с мест. Этот пункт и есть первая точка работы после возвращения.
