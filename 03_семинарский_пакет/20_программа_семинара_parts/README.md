# Разбивка программы семинара на части (для ИИ-агентов)

> Если ваш ИИ-агент имеет ограничение на размер сообщения (например, 60–130 KB),
> отправляйте ему по одной части из этого каталога. Полная программа — 90 KB,
> в одно сообщение может не влезть.

## Оглавление

| Часть | Файл | Содержание |
|---|---|---|
| 1 | `part_01_общее.md` | Обложка, организаторы, партнёры, цели, ожидаемые результаты, сводное расписание |
| 2 | `part_02_25_08_покровский.md` | День 1 (25.08, вторник), Площадка № 1 — ДСО «Покровский» (11 страниц PDF) |
| 3 | `part_03_26_08_тесовый_берег.md` | День 2 (26.08, среда), Площадка № 2 — ДСО «Тесовый берег» (10 страниц PDF) |
| 4 | `part_04_27_08_победа_парус.md` | День 3 (27.08, четверг), Площадки № 3 и № 4 — кинокомплекс «Победа» и ДСО «Парус» + пленарная сессия |
| 5 | `part_05_состав_и_кросс_ссылки.md` | Состав спикеров (модераторы, эксперты, директора) + перекрёстные ссылки на основной доклад |

## Рекомендации по использованию

**Сценарий 1: агент готовит выступление о питании (доклад).**
→ Загрузите `part_01_общее.md` + `part_05_состав_и_кросс_ссылки.md` (≈15 KB).
  В части 5 — кейс Серафимовского (Чистяков Е.В.), который напрямую связан
  с разделами 25–29 доклада.

**Сценарий 2: агент анализирует тематику семинара (что обсуждают в ПНИ в 2026).**
→ Загрузите `part_01_общее.md` + `part_02` + `part_03` + `part_04` по одной в каждом
  сообщении (или все вместе, если контекст позволяет). Части 2–4 содержат
  ВСЕ заголовки сессий — по ним видно таксономию тем.

**Сценарий 3: агент помогает модератору конкретной сессии.**
→ Загрузите `part_01_общее.md` (контекст дня) + соответствующую `part_02/03/04`.
  Внутри — цели, задачи, вопросы для обсуждения, ФИО модератора и экспертов.

**Сценарий 4: агент проверяет, не противоречит ли программа докладу.**
→ Загрузите `part_05_состав_и_кросс_ссылки.md` (прямые перекрёстные ссылки)
  + нужный `part_02/03/04`.

## Согласованность частей

Каждая часть самодостаточна для своей темы, но содержит гиперссылки
в виде Markdown-якорей на смежные части. Источник страниц PDF отмечен
комментариями `<!-- Источник: страница N -->`, чтобы можно было свериться
с оригиналом без перекрёстных ссылок.

## Полная программа

Если контекст вашего агента ≥ 130 KB, используйте сразу
`../20_программа_семинара_25-27_08_2026.md` — это единый файл 90 KB.

Если контекст меньше — отправляйте части последовательно, начиная с части 1.
