## Как пересобрать

Из корня репозитория (нужны pandoc, WeasyPrint, poppler — см. `.cursor/install.sh`):

```bash
python3 проект/scripts/build_speaker_kit.py
```

Скрипт пересобирает презентацию (`build_v5.py`), доклад (`build_doklad.py`), материал (`build_material.py`) и рендерит сценарий и Q&A из `07_редакция_доклада_v2/08_версии/`.
