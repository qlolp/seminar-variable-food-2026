# Ступени участия (ось жителя)

Мера контроля над едой, возвращённого человеку. **Не** модели раздачи М0–М5. Доклад (гл. 8.6) предупреждает: нумерация не совпадает.

Вопрос ступени: что изменилось в тарелке **этого** жителя сегодня?

| Ступень | Смысл (гл. 8.6) |
| --- | --- |
| 0 | Еду определили регион — кухня — смена |
| 1 | Спросили; тарелка та же |
| 2 | Выбор дошёл до тарелки сегодня |
| 3 | Дошли ещё время и место |
| 4 | Влияет на меню через совет жителей |
| 5 | Еда снова часть жизни, не процедуры |

Раздатка 08 формулирует чуть иначе (1 — «спрашивают, готовят одно»; 2 — «два варианта на линии ежедневно»). Это **не** М1/М2. Путаница — известный зазор пакета; см. [gaps](../gaps.md) п. 1.

Доклад v2 (п. 1.4, [`doklad.md`](../../raw/sources/variativnoe-menu-doklad-2026-v2/doklad.md)) снял её примерами (толкование): два вторых, житель получил названное — М1 / ступень 2; вариант Б кончился к концу раздачи — М1 / ступень 1 для стоявших в конце; милосердию везут только А «потому что проще» — М1 / ступень 0; анкета раз в год при одном меню — М0 / ступень 1; выбор из двух протёртых блюд — М1–М2 / ступень 2. Правило отчёта — обе цифры через косую черту по отделению.

Ступени 3–5 — тренировка навыка для сопровождаемого проживания, не «ресторан в интернате». Ближайший год для большинства домов — 1–2.

Проверка через жителя по имени, не через документ.

Публичный пример ступени 4 — «кулинарные советы» из проживающих в домах соцобслуживания Тюменской обл., которые «формируют меню» (сообщение департамента 15–16.10.2026, по копии; [проверка 22.10.2026](../sources/gossektor-obzor-2026-10-22.md)). Совет не делает меню вариативным: модель раздачи (М0–М5) из сообщения не определяется, а «выборное меню» есть только в одной из двух редакций — не сглаживать.

Совет дома Кировского дома-интерната анкетирует проживающих, в том числе по повседневному меню (архив портала министерства; дата на странице не указана; [проверка 23.10.2026](../sources/gossektor-obzor-2026-10-23.md)). Это та же ось участия. Сообщение не показывает, что анкета дошла до тарелки конкретного жителя, и номер ступени по нему не ставится.

Опросы Собинского дома социального обслуживания, по которым составляется сезонное меню (самоотчёт 25.09.2026), и инфоматы «для сбора предпочтений» на площадке Красавинского дома (МК Вологда, 04.07.2026) лежат на той же оси. Ни газета, ни новость учреждения не показывают, что ответ конкретного жителя изменил его тарелку; номер ступени не ставится ([наводки 26.10.2026](../sources/gossektor-obzor-2026-10-26-tips.md)). Щадящее питание по рекомендации врачей в Собинке — персонализация, не ступень выбора.
