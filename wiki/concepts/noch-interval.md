# Ночной интервал ужин → завтрак

Выбор блюда не лечит 15 часов без еды. Операционная цель дома в докладе: **не больше 13 часов**. Это рабочий ориентир авторов внутри международного диапазона 11–14 ч, **не** российская норма. 14 часов — верхняя граница CMS (США), не целевой показатель нашего чек-листа.

Пример «ужин 17:30 → завтрак 8:30 = 15 ч» — учебный, не среднее по РФ.

Если больше 13: сдвинуть ужин позже или завтрак раньше, либо вечерний перекус по согласованию с врачом. Второй ужин в СанПиН — инструмент, не украшение расписания.

В Серафимовском по архиву сайта (февраль 2026): второй ужин 20.00–21.00, завтрак 8.00–10.00 → **11–12 часов**. Это факт одного дома, не норматив отрасли.

Замер: одна строка в журнале вчерашний ужин → сегодняшний завтрак, по факту, не по положению.
