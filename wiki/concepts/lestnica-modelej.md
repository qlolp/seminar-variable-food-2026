# Модели организации раздачи (М0–М5)

Технология стола, не «мера счастья». Каждая модель — рабочая конфигурация с ценой и рисками. **Нумерация не совпадает** со [ступенями участия](lestnica-uchastiya.md) (гл. 8.6). Форма самоопределения в пакете меряет **эту** ось.

| Модель | Суть | Где подтверждено публично |
| --- | --- | --- |
| **М0** | Мономеню; отказ → замена по таблице; остатки влияют на цикл | Фундамент, не вариативность |
| **М1** | Второй вариант одной ключевой позиции, не каждый день | [Болотнинский](../entities/bolotninskiy-pni.md) (в момент еды, несколько дней в неделю); Каменский ПНИ; [Серафимовский](../entities/serafimovskiy.md) (заказ накануне) |
| **М2** | Два варианта основных позиций ежедневно | [Успенский](../entities/uspenskiy-pni.md) (2024); [Усть-Илимский](../entities/ust-ilimskaya.md) (М1 → М2); формат [Иркутской обл.](../entities/irkutskaya-oblast.md) — только вторичка |
| **М3** | Житель комплектует тарелку на линии | [Успенский](../entities/uspenskiy-pni.md) — «шведский стол» (2025 часть отделений, 2026 все пищеблоки); линия [ДДСОЛ](../entities/ddsol.md) — самообслуживание без доказанного выбора; не «типовой ПНИ» |
| **М4** | Семейная подача, сами накладывают | Международный эффект у пожилых с деменцией; точечно |
| **М5** | Жители готовят (квартира тренинга) | Горизонт сопровождаемого проживания, не массовая модель |

М1–М2 подтверждены российской практикой; М3 с 2025–2026 гг. — один публичный дом (Успенский), со словами учреждения вместо измерений. Российский старт — не прыжок на М3.

Доклад v2 (п. 1.4) держит три шкалы раздельно и даёт правило отчёта (рекомендация): по каждому отделению две цифры через косую черту — «М1 / ступень 2 в общем, М1 / ступень 0 в милосердии». Одна цифра без названия лестницы не пишется. «М1 ≠ ступень 1» закрыто в v2 (гл. 9 п. 41).

Предшественник 22.07 считает «модели» иначе (гл. 4.3: напиток → гарнир → один компонент → два блюда → линии → предзаказ → выбор у раздачи → визуальный выбор → полная индивидуализация). Академический аудит G21 чинил «11 ступеней». Правовой обзор НПА (§ 4.2) даёт **третью** нумерацию — пять моделей: двухвариантное; меню-заказ на неделю; шведский стол; смешанная (несколько раз в неделю); событийная. Болотнинский там отнесён и к первой, и к четвёртой; v2 ставит его в одну клетку — М1 / смешанная (гл. 9 п. 8). Ни одна из трёх шкал не подменяет М0–М5 и не склеивается со [ступенями участия](lestnica-uchastiya.md). Сводка: [gaps](../gaps.md).

Тихий регресс (гл. 8.5): уходит инициатор → показ «упрощают» → журнал «для проверки». Снаружи положение действует. Читается в панели: падает доля выбирающих Б, пустеет журнал срывов.

Правило формы: ступень — **вчерашний день**, не положение. Три вопроса: вчерашний журнал; был ли Б на линии; кто выбрал не стандарт.
