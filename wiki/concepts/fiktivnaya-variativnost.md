# Фиктивная вариативность

Положение написано, выбора вчера не было. Для проверяющего это хуже честного М0: имитация контроля — типовой состав дел, а житель остаётся без голоса.

Пять признаков (раздатка 08): журнал одной рукой за неделю; «стандартных» >90 %; жители не помнят выбора; вариант Б «закончился» при пустом журнале срывов; выбор только каши на завтрак при «полной вариативности» в положении. Два признака — перезапуск.

Предшественник (22.07) формулирует жёстче: формальная имитация иногда **опаснее** открытого отсутствия вариативности.

Проверка реальности — факты вчерашнего дня, не документ. Экспресс: спросить жителя «что ты сегодня выбрал»; мойка после обеда; ночной интервал по расписанию и по факту; что делает сиделка на третьем отказе; сырьевая строка за пять минут.
