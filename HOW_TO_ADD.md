# Как положить новый источник в wiki

Это инструкция для меня (Чистяков) и для агента. Семинар уже прошёл: репозиторий — **wiki по вариативному меню**, не архив зала. Сырьё кладу я. Страницы пишет агент. Готовые файлы в `raw/` агент **не правит**.

Полные конвенции — [`AGENTS.md`](AGENTS.md). Каталог — [`wiki/index.md`](wiki/index.md). Чего ещё нет — [`wiki/gaps.md`](wiki/gaps.md).

---

## Пять шагов

### 1. Кладём иммутабельные файлы в `raw/sources/<slug>/`

`<slug>` — латиница, коротко: `sanpin-4282-26`, `prikaz-124-scan`, `variabelnoe-menu-pni`.

В каталог кладём **как есть**: PDF, markdown, снимок README соседнего репо, короткую служебную записку. Не «улучшаем» формулировки источника. Если это соседний GitHub — сначала stub `raw/sources/related/<name>/README.md` с URL и статусом ingest, затем копируем только те файлы, которые реально читаем.

Агент сам туда ничего не выдумывает и не переписывает уже лежащее.

### 2. Говорим агенту

```
ingest raw/sources/<slug>
```

Этого достаточно. Не нужно присылать «сделай красивую раздатку». Агент читает источник и обновляет wiki.

### 3. Агент обновляет wiki — и только wiki

После ingest должны измениться:

- `wiki/sources/<slug>.md` — сводка источника;
- затронутые `wiki/concepts/` и `wiki/entities/` (часто несколько страниц; новую — только если темы ещё нет);
- `wiki/index.md` — ссылка и одна строка;
- `wiki/overview.md` — живой синтез, не оглавление;
- `wiki/gaps.md` — что закрылось и что осталось;
- `wiki/log.md` — **append**:

```markdown
## [YYYY-MM-DD] ingest | Краткое имя источника
```

`raw/` в том же ходе не редактируется. Противоречия не затираются «поздним» текстом.

### 4. По желанию: сильный ответ кладём в `wiki/queries/`

Если вопрос директору дома стоит того, чтобы к нему вернуться («где Серафимовский на лестнице», «что ответить проверяющему»), агент сохраняет ответ в `wiki/queries/` и добавляет строку в index + log (`query`, не `ingest`).

### 5. Периодически lint

```
python3 .github/check_wiki.py
```

Проверяет каркас wiki, frontmatter, живые wikilinks и отсутствие печатной кухни. Не проверяет список листовок. После чистки ссылок — append в `wiki/log.md`: `## [YYYY-MM-DD] lint | Что проверяли`.

## Примеры

### Новый PDF (норма или локальный акт)

Я получил скан постановления СПб о нормах питания (без персональных данных).

1. Кладём файл: `raw/sources/spb-normy-pitaniya/постановление.pdf` и короткий `README.md` (что это, дата, откуда).
2. Пишем агенту: `ingest raw/sources/spb-normy-pitaniya`.
3. Агент заводит `wiki/sources/spb-normy-pitaniya.md`, правит страницы норм и пробелов, **не** пересказывает PDF «своими цифрами», если цифр в источнике нет.
4. Lint.

Не класть в wiki скан с ФИО жителей.

### Соседний репозиторий GitHub

Нужен полный доклад-предшественник, не лёгкий снимок.

1. В `raw/sources/related/variabelnoe-menu-pni/` уже есть stub. Копируем туда `output/report.md` и главы **как в upstream**, без правки текста.
2. Пишем агенту: `ingest raw/sources/related/variabelnoe-menu-pni`.
3. Агент обновляет `wiki/sources/variabelnoe-menu-pni.md`, сверяет 22 главы с 44 главами «Не просто накормить», расхождения оставляет в `wiki/gaps.md`. Не выдумывает CSV, которых не копировали.

Другой соседний репо — тот же путь: stub README с URL → копия файлов → `ingest raw/sources/related/<name>`.

### Короткая записка директора

Я измерил отходы за семь дней на одном отделении и хочу, чтобы wiki это знал.

1. Кладём текст: `raw/sources/serafimovskiy-otkhody-2026-09/NOTE.md` (даты, отделение без ФИО, что измерили, чего не измеряли). Это сырьё, не страница wiki.
2. Пишем агенту: `ingest raw/sources/serafimovskiy-otkhody-2026-09`.
3. Агент обновляет [Серафимовский](wiki/entities/serafimovskiy.md) и [пробелы](wiki/gaps.md). Не обобщает «весь дом» и не превращает замер в норму СанПиН.

## Чего не делать

- Не просить агента «добавить в раздатку» или нарисовать диплом викторины. Печать зала сюда больше не кладём.
- Не править `raw/sources/ne-prosto-nakormit/doklad/` «чтобы звучало лучше». Это канон литературной редакции.
- Не подменять ingest пересказом из памяти: сначала файл, потом команда.
- Не ждать, что wiki сам следит за сайтами. Нет файла в `raw/` — нет факта в wiki.
