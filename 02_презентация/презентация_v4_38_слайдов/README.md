## Юридические и статистические оговорки (в речи, не в подвале)

- 74 % — одна цифра, без «четыре из пяти»; источник — «Если быть точным», данные за 2024 год
- 15 часов — пример расписания, не «типовой дом РФ»; цель дома ≤13 ч
- Дисфагия 21,9–69,5 % — клинические группы, не все ДСО
- Успенский = М2, не буфет; буфет — ДДСОЛ
- Тесовый берег — 44-ФЗ; Серафимовский — 223-ФЗ
- Не выдумывать «30 % котлет» / «40 % отходов»
