## Подача на 90 минут

Основной показ — **20 слайдов** (в PDF: 1–20). Резерв после финальной цитаты — не листать, пока зал не спросит.

- **Пролог:** титул → три конфликта → боль («один обед — пять конфликтов»)
- **Контекст:** 2 190 приёмов в год → 74 % (почти три из четырёх; данные за 2024 год, «Если быть точным», не ТАСС) → ночной интервал, цель дома ≤13 ч
- **Право:** ответ проверке — папка (положение, журналы, карты, учредитель), не формула «запрета нет». Гуманное отношение — ст. 5 ч. 2 3185-1
- **Опыт и кейс:** шесть практик (Успенский = М2, не буфет) → заказное питание → приказ № 124 → мост к со-модератору (44-ФЗ)
- **Врач раньше кухни:** граница врача, Campforts 2023 → пары эквивалентов → лечебное × вариативное → каналы воли
- **Путь директора:** замер → приказ → смена → 90 дней одно отделение → масштаб М1–М2
- **Действия:** три ошибки → СанПиН 01.09.2026 → пилот 90 дней (возврат к цикличке, если не сдвинулось) → **измеряйте**

Резерв: цветная метка по краю (синий — право, оранжевый — деньги, зелёный — кухня, бирюза — клиника). Легенда — на первом слайде резерва.

## Юридические и статистические оговорки на слайдах

- 74 % — одна цифра, без «четыре из пяти» / «7 из 10»; источник — проект «Если быть точным», данные за 2024 год, не текущая статотчётность Минтруда
- Недееспособность не лишает права выражать мнение (ст. 29 ГК); выбор блюда — не сделка
- 442-ФЗ не устанавливает прямого права на ежедневный выбор блюда
- 15 часов — пример расписания, не «типовой дом РФ»
- Текстуру назначает врач; IDDSI — язык описания консистенции

## Принципы

- Минимум текста: ключевой тезис, цифра, источник в подвале — остальное устно
- Каждая диаграмма доказывает тезис слайда, а не украшает его
- Крупные цифры (185 px «2 190», donut 74 %) читаются с последнего ряда
- Сторителлинг: контекст → проблема → решение → призыв к действию
- **Пиктограммы и иллюстрации:** линейные иконки в палитре деки, «лента суток» с ночным окном как примером, QR-код репозитория на слайдах «Материалы» и «Спасибо» (`slides/qr.png`)
- Синхронизирована с докладом (разделы 5, 8, 15–16, 17.12, 19, 25.5, 29, 35; источники S-реестра)
