## Подача (по принципу «одна мысль — один слайд»)

- **Пролог (1–3):** титул → формат шести вопросов → разогрев с залом
- **Контекст (4–6):** гигантская цифра 2 190 (6 приёмов в день в ДСО «Серафимовский» × 365) → donut 74 % → ночной интервал: «лента суток» + бары в единой шкале 24 ч
- **Проблема и право (7–8):** цепочка решений без жителя → правовая рамка
- **Опыт и кейс (9–13):** шесть практик → что сделали → цена и предел → приказ № 124:
  заказное питание (вариативное меню) закреплено правилами внутреннего распорядка
  жителей, включая маломобильных → мост к со-модератору
- **Две лестницы (14–15):** вариативность 0–5 и участие 0–5
- **Шесть вопросов (16–30):** каждый в связке «суть → график → вопрос залу»;
  современные графики: slope-chart «до/после» IDDSI (44→90 %, 31→100 %),
  бары стоимости, А/Б-голосование карточками с цветной полосой
- **Переход и действия (31–33):** три ошибки → таймлайн сентября → три шага с понедельника
- **Финал (34–38):** смежные площадки → материалы → открытый микрофон →
  тёмный финальный слайд с цитатой → контакты

## Принципы

- Минимум текста: ключевой тезис, цифра, источник в подвале — остальное устно
- Каждая диаграмма доказывает тезис слайда, а не украшает его
- Крупные цифры (185 px «1 095», donut 74 %) читаются с последнего ряда
- Сторителлинг: контекст → проблема → решение → призыв к действию
- **Пиктограммы и иллюстрации:** 35 линейных иконок в палитре деки (столовые приборы,
  продукты, луна, весы, печать, корзина, люди), «лента суток» с ночным окном 15 ч,
  пиктограмм-график «7 из 10», иконки продуктов в парах эквивалентов,
  QR-код репозитория на слайдах «Материалы» и «Спасибо» (`slides/qr.png`)
- Синхронизирована с докладом (разделы 5, 8, 15–16, 17.12, 19, 25.5, 29, 35; источники S-реестра)
