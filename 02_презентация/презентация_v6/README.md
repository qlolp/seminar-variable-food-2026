## Структура презентации

- **18 слайдов основного показа** (хронометраж ≈ 19 мин, плюс 1 мин резерва на паузы).
- **1 разделитель «Резерв — не листать»** (после 18-го слайда).
- **12 резервных слайдов** R1–R12 (не показывать без вопроса аудитории).

Структура основного маршрута:

1. Титул
2. Пять измерений одного обеда
3. Дисфагия (21,9–69,5 %)
4. 2 190 приёмов в год
5. 74 % — почему выбор это не «каприз»
6. Ночной интервал: 15 ч vs ≤13 ч
7. Проверяющему — комплект, не лозунг
8. Иркутская область — масштаб региона
9. Серафимовский: житель заказывает ужин накануне
10. Приказ № 124 от 10.03.2026
11. 223-ФЗ / 44-ФЗ
12. Сначала врач, потом выбор
13. Модель решения: 4 шага
14. Четыре канала воли
15. Пять шагов директора + пять показателей

17. 01.09.2026 — новый СанПиН

## Редактирование

### Открыть и поправить в PowerPoint

1. Открыть `Презентация_v6_Не_просто_накормить.pptx` в PowerPoint или LibreOffice Impress.
2. Все слайды лежат на пустых макетах (slide layout 6 = blank) — можно править без разрушения макета.
3. Шрифты заданы по именам. Если на машине нет Playfair Display / PT Sans, установить из `source/fonts/`:
   - Windows: скопировать `source/fonts/PTSans-*.ttf` в `%LOCALAPPDATA%\Microsoft\Windows\Fonts\`. Playfair Display нужно скачать OFL-версию отдельно (например, с Google Fonts).
4. Сохранить как `.pptx`.

### Изменить тексты

Тексты слайдов 1–18 находятся в `build/build_v6.py` (`slide_01_title` … `slide_19_separator`).
Тексты слайдов R1–R12 — в `build/reserve_v6.py` (`slide_R1_warmup` … `slide_R12_metrics`).

После правки:

```powershell
cd "C:\Users\Evgenii\OneDrive\Desktop\seminar\seminar-variable-food-2026\02_презентация\презентация_v6\build"
python build_v6.py
```

Скрипт пересоберёт `.pptx` в текущую директорию. Скопировать в корень `презентация_v6/`:

```powershell
Copy-Item .\Презентация_v6_Не_просто_накормить.pptx ..\Презентация_v6_Не_просто_накормить.pptx -Force
```

### Перегенерировать PDF

В каталоге `build/`:

```powershell
# Скопировать .pptx во временный файл с ASCII-именем (нужно для LibreOffice)
Copy-Item .\Презентация_v6_Не_просто_накормить.pptx .\work.pptx -Force

# Конвертировать в PDF
cmd /c "\"C:\Program Files\LibreOffice\program\soffice.exe\" --headless --norestore --convert-to pdf --outdir . .\work.pptx"
```

Получится `build\work.pdf` (31 страница). Скопировать в корень:

```powershell
Copy-Item .\work.pdf ..\Презентация_v6_Не_просто_накормить.pdf -Force
```

### Сделать PDF без резерва (только 18 основных)

```python
# Скрипт в build\make_main_pdf.py
import pypdfium2 as pdfium
pdf = pdfium.PdfDocument(r"..\Презентация_v6_Не_просто_накормить.pdf")
out = pdfium.PdfDocument.new()
for i in range(18):
    out.import_pages(pdf, [i])
out.save(r"..\Презентация_v6_Не_просто_накормить_без_резерва.pdf")
```

### Добавить или поменять шрифт

Шрифты лежат в `source/fonts/`:

- `playfair-{400,600i,700,800,900}.woff2` — для вёрстки HTML (не для PowerPoint).
- `PTSans-{Regular,Bold}.ttf` — реально используется в `.pptx` (установлен в пользовательский каталог шрифтов).

Если добавить новый шрифт:

1. Положить TTF в `source/fonts/`.
2. Установить в систему (`%LOCALAPPDATA%\Microsoft\Windows\Fonts\` на Windows).
3. В `build/build_v6.py` найти все `add_textbox(...)` и поправить `font=...`.

## Что важно знать перед сценой

- **На флешке:** `Презентация_v6_Не_просто_накормить.pdf` (с резервом) **и** `Презентация_v6_Не_просто_накормить_без_резерва.pdf` (только основной показ). Если показ по таймингу поджимает — показать версию без резерва.

## Что не входит в v6

- Видео и анимации (намеренно: презентация должна работать в любом зале и на любом проекторе, включая старые).
- Декоративные иконки и клипарт (намеренно: «редакционная типографика, тёплая палитра, спокойная уверенность»).
- Фотографии жителей (намеренно: «не использовать эмоциональные фотографии уязвимых людей, создающие стигматизацию или нарушающие достоинство»).
- Сгенерированные ИИ изображения (намеренно: «изображения, сгенерированные ИИ, выдаваемые за реальные учреждения»).
- Выдуманные цифры про «40 % отходов» или «30 % не едят котлеты» (намеренно: таких данных нет в источниках).
- Юридические преувеличения (намеренно: приказ № 124 — локальный акт, не федеральный норматив; 442-ФЗ — не буквальное право на ежедневный выбор).
