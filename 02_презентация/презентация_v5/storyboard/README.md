## Решения по сравнению с v4

- **18 слайдов основного показа** (вместо 21). ~55 сек/слайд.
- **12 резервных слайдов** (вместо 19), стратифицированы по темам.
- **Дизайн-система сохранена** без изменений: `#FAF9F5 / #F0EEE6 / #141413 / #C15F3C`, Playfair Display + PT Sans, 16:9.
- **Драматургия перестроена**: вход через пять измерений одного обеда → дисфагия → масштаб → недееспособность → ночной интервал → документ-папка → российская практика (одна история, а не шесть) → кейс Серафимовского → приказ № 124 → закупки → медицинская рамка → модель решения → каналы воли → пять шагов → три ошибки → 01.09.2026 → пилот-финал.
- **Юридические оговорки заострены**: Campforts 2026 (НЕ 2023, уточнено 19.08.2026); 21,9–69,5 % — отдельные изученные клинические группы; 74 % — расчёт «Если быть точным», 2024; 15 ч — пример расписания, не статистика; наблюдение — сигнал, а не согласие; IDDSI — язык описания, не диагностический протокол.
- **v4 не трогаем** — все изменения в новой директории.
