# Исходники презентации v2

Здесь лежат исходные файлы, из которых собрана `../Не_просто_накормить_презентация_v2.pdf`. Правьте здесь — потом регенерируйте PDF.

## Состав

- `slide-01.html` … `slide-30.html` — 30 слайдов в формате HTML, размер каждой страницы 960×540 px (16:9).
- `imgs/cover.jpg`, `imgs/dining_community.jpg`, `imgs/chef_plating.jpg` — 3 изображения, сгенерированы через image_synthesize.
- `build_pdf.py` — скрипт сборки: каждый HTML → PDF (Edge headless), затем склейка через pypdf.

## Размеры и шрифты

- Все слайды — 960×540 px.
- Шрифт — **Times New Roman** (требование html-presentation-generator skill, единственный шрифт, который корректно конвертируется в PPTX без потерь).
- Палитра — `#10 «Образование и диаграммы»`: `#264653` (тёмный teal), `#2a9d8f` (мята), `#e9c46a` (золото), `#f4a261` (оранжевый), `#e76f51` (коралл). Других цветов в файлах нет.
- Стиль «Soft & Balanced» — профессиональный, без излишней игривости.

## Правка одного слайда

1. Откройте нужный `slide-NN.html` в любом редакторе.
2. Все стили — inline в `style="…"` на каждом элементе. Никаких внешних CSS, никаких `<style>` блоков (кроме служебного сниппета Appendix A в `<head>`).
3. Картинки в HTML ссылаются на `imgs/cover.jpg` и т. д. — относительный путь. При переносе в другое место сохраняйте ту же структуру.
4. После правки запустите `python build_pdf.py` — пересоберётся PDF в `../Не_просто_накормить_презентация_v2.pdf`.

## Добавление нового слайда

1. Скопируйте любой существующий `slide-NN.html`, переименуйте.
2. Смените номер в `<title>`, в подписи страницы (внизу справа, SVG с цифрой) и в тексте.
3. Обновите `build_pdf.py` — он автоматически подхватывает все `slide-*.html` через `glob`.
4. Запустите сборку.

## Сборка PDF

### Требования

- Windows + Microsoft Edge (любая современная версия).
- Python 3.x с установленным `pypdf`: `pip install pypdf`.
- Edge обычно здесь: `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`. Если путь другой — отредактируйте константу `EDGE` в `build_pdf.py`.

### Запуск

```powershell
cd <путь-к-репо>\02_презентация\презентация_v2_30слайдов\source
python build_pdf.py
```

Скрипт: 30 × Edge headless → 30 PDF в `out/`, затем pypdf склеивает в `../Не_просто_накормить_презентация_v2.pdf`. Время: ~2 минуты на 30 слайдов.

### Возможные проблемы

| Симптом | Причина | Решение |
|---|---|---|
| `WARNING: in the working copy … LF will be replaced by CRLF` | нормально для Windows | игнорировать |
| `PDF: file missing after Edge` | гонка: Edge закрылся раньше, чем записал файл | `build_pdf.py` ждёт 0.3 с между слайдами; при частых сбоях увеличить до 1.0 |
| `ModuleNotFoundError: pypdf` | не установлено | `pip install pypdf` |
| Имена файлов в cp866 (кракозябры) | косметика PowerShell | не влияет на сам файл; имя на диске в UTF-8 |

## Синхронизация с докладом

Все правки в `01_доклад/Не_просто_накормить_доклад.html` от 18.08.2026 уже учтены в этих слайдах. Если в доклад вносятся новые правки — обновите соответствующие слайды (названия и номера разделов в источниках в подписях слайдов) и пересоберите PDF.

## Что НЕ редактируется в HTML

- `Appendix A` (служебный сниппет в `<head>` для масштабирования при просмотре в браузере) — оставлен как есть.
- Прозрачные SVG-фигуры для декора (точки, круги) — менять цвет и opacity можно, менять геометрию не нужно.
