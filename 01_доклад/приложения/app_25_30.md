# Приложения 25–30

## Приложение 25. Форма семидневного замера отходов

*Проект локальной формы. Не является нормативно установленным документом. Требует адаптации.*

До пилота и на 80–90-й день. Обычная неделя, не праздник. Кухонные весы, конец каждого приёма. Тарелочные остатки и кухонные — раздельно.

| День | Приём пищи | Тарелочные остатки, кг | Кухонные остатки, кг | Число порций | Остаток на порцию, г | Примечание |
|---|---|---|---|---|---|---|
| 1 | завтрак | | | | | |
| 1 | обед | | | | | |
| 1 | ужин | | | | | |

Итоги недели: средний остаток на порцию ___ г; топ-3 блюда по остаткам ________; сравнение с замером «до» (при повторном замере): ___ %.

Честность замера. Меню недели не «улучшать». Сменам не объявлять проверку — исказят поведение. Праздник, похороны, обострение — в примечание, не вычёркивать молча.

## Приложение 26. Форма учёта трудозатрат на кормление

*Проект локальной формы. Не является нормативно установленным документом. Требует адаптации.*

Три типичных дня. Каждый приём. Секундомер. Поведение смены не трогать.

| День/приём | Число жителей, нуждающихся в помощи | Число помогающих | Время приёма пищи, мин | Суммарные минуты помощи | Минут помощи на жителя | Кто не получил помощь вовремя |
|---|---|---|---|---|---|---|
| | | | | | | |

Дефицит: потребность (жители × нормативные минуты) − имеющиеся минуты = дефицит в минутах. Дальше — в ставки: делить на продолжительность рабочего времени. Это основание письма учредителю (приложение 33).

## Приложение 29. Проект положения о вариативном питании

*Проект локальной формы. Не является нормативно установленным документом. Требует адаптации.*

Разделы и формулировки:

1. **Общие положения.** Цель: права жителей (ст. 37, 43 закона № 3185-1) — через организованный выбор в питании. Положение стоит на действующих нормах (СанПиН 2.3/2.4.3590-20; рекомендованные нормы — приказ Минтруда № 520н, статус в регионе — ___).
2. **Перечень вариативных позиций** и режим (дни, приёмы пищи).
3. **Гарантия стандартного варианта:** «житель, не сделавший выбор, получает полноценный стандартный вариант; выбор — право, а не обязанность».
4. **Порядок показа меню и фиксации выбора** (визуальное меню, формы, сроки передачи заказа).
5. **Замены и отказы:** порядок, журналы, запрет использования еды как поощрения/наказания, запрет принудительного кормления.
6. **Связь с назначениями врача:** конфликт «выбор против назначения» решает врач в день обращения; диетические столы имеют собственные пары эквивалентов.
7. **Роли и ответственность** (по матрице, приложение 17).
8. **Контроль:** проверки реальности выбора (приложение 24), панель чисел, отчётность учредителю.
9. **Совет жителей** — со ссылкой на положение (приложение 30).

## Приложение 30. Положение о пищевом совете жителей

*Проект локальной формы. Не является нормативно установленным документом. Требует адаптации.*

1. **Состав:** 5–9 человек — жители (квота по отделениям; интересы недееспособных представляют выбранные ими лица или члены совета), сиделка, повар; врач — с правом совещательного голоса. Срок — 1 год, ротация — половина состава.
2. **Полномочия:** обсуждение меню до утверждения; дегустации новых позиций; сбор и ранжирование пожеланий; ответ администрации на пожелания — до 14 дней.
3. **Ритм:** заседание ежемесячно; кворум — половина состава; протокол ведётся и хранится ___ лет.
4. **Права совета:** запрашивать меню, журналы срывов, панель чисел; выносить предложения директору; инициировать дегустации.
5. **Границы:** совет не подменяет врача и не отменяет санитарные требования. Если позиция администрации расходится с зафиксированными предпочтениями жителя — приоритет у предпочтений, пока они не противоречат назначениям врача.
6. **Форма протокола:** дата, состав, вопросы, решения, сроки, ответственные.
