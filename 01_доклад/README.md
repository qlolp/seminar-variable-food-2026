# Доклад «Не просто накормить…» — версии

## Что здесь

- `Не_просто_накормить_доклад.html` — основная HTML-версия. Со всеми визуальными элементами, схемами, фигурами. Открывается в браузере.
- `Не_просто_накормить_доклад.md` — **Markdown-версия**. На титуле — автор и должность. Раздел 4 — вход за 15 минут. Раздел 44 — полный список источников.
- `Не_просто_накормить_доклад_официальный.pdf` — официальный PDF (**332** стр., Times New Roman 14 pt, полуторный интервал). Для печати и официальной публикации.
- `Не_просто_накормить_доклад_журнальный.pdf` — журнальный PDF (**274** стр., цветная обложка). Для раздаточных материалов.
- `Не_просто_накормить_доклад_красивая_версия.pdf` — презентационная версия (**248** стр., тёмно-синяя обложка, Playfair Display + PT Serif). Для подарков и спецслучаев.
- `Не_просто_накормить_доклад_стиль_claude.pdf` — версия в едином стиле с презентацией v4 (**239** стр., слоновая кость + терракота).
- `Не_просто_накормить_доклад.docx` — редактируемая DOCX-версия. Для правки и пересылки (может отставать от последней Markdown/PDF-сборки).

Числа страниц — после сборки 21.08.2026 (v1.3, с краткой версией); при следующем рендере они могут сдвинуться на 1–3 страницы. На семинар в зал — версия «стиль claude». Остальные вёрстки остаются в репозитории.

## Markdown-версия — что внутри

- Структура: 44 раздела основного текста, объединённые в девять частей, 22 учебных кейса, 45 приложений (h1 — 64 заголовка с учётом разделителей частей и блоков; h2 — 398 подразделов).
- Краткая версия (дайджест для руководителя, «вечер чтения») — встроена в доклад перед частью II; отдельно: `проект/output/_digest.html` и PDF по `проект/scripts/build_digest.py`.
- 22 учебных кейса с разборами.
- 45 приложений-шаблонов локальных форм.
- 4 части: основной доклад → кейсы → приложения → инфографики.
- Сноски сохранены как `^N^` (вместо `[^N]` — так быстрее конвертировалось из HTML; для точного вида заменить через regex, если нужно).
- Синхронизирована с HTML после правок 20.08.2026 (библиография в разделе 44, реестр 34 записи, юридические оговорки ст. 29 ГК / 442-ФЗ).

## Как работать с Markdown через ИИ-агента

### Быстрые промпты

- **«Найди в докладе всё про дисфагию»** — агент прочтёт разделы 10, 17, 27, вернёт контекст с указанием разделов.
- **«Сделай краткое резюме раздела 17 (Право РФ) на 200 слов»** — агент выделит главное: цепочка Конституция → 3185-1 → 442-ФЗ → ИППСУ, запрет выбора отсутствует, ИППСУ как механизм.
- **«Что говорит доклад про аутсорсинг? Какие 8 строк должны быть в контракте?»** — раздел 42 + приложения 43, 44.
- **«Сравни подход Новосибирской области и ДСО Серафимовский по внедрению вариативности»** — раздел 25, кейсы 14, 22.
- **«Перепиши раздел 11.3 (литий) для врача, не для кухни»** — смена аудитории через агента.

### Что НЕ спрашивать у агента

- Клинические назначения для конкретного жителя — доклад не заменяет врача.
- Юридические заключения для конкретного случая — доклад не заменяет юриста.
- Актуальные редакции НПА — источники приведены по состоянию на 17.08.2026, для свежей версии нужна платная правовая база.

### Ограничения Markdown-конверсии

- Сноски упрощены: `^1^` вместо `[^1]`. Если нужны настоящие ссылки на сноски, используйте HTML-версию.
- Сложные таблицы могут потерять выравнивание — для печати используйте PDF.
- Визуальные элементы (схемы, фигуры) — только в HTML/PDF.
- Некоторые места с особым форматированием (жирный + курсив) могут рендериться иначе, чем в HTML.

## Регенерация Markdown из HTML

Актуальный источник текста — `проект/chapters/*.md`; сборка всех версий (MD/HTML/PDF) запускается скриптами из `проект/scripts/` репозитория (`build.py`, `build_html.py`, `build_color.py`, `build_beautiful.py`, `build_claude.py`). Если правите главы — пересобирайте версии этими скриптами, чтобы MD, HTML и PDF оставались синхронными.
