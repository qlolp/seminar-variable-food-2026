## Как работать с Markdown через ИИ-агента

### Быстрые промпты

- **«Найди в докладе всё про дисфагию»** — агент прочтёт разделы 10, 17, 27, вернёт контекст с указанием разделов.
- **«Сделай краткое резюме раздела 17 (Право РФ) на 200 слов»** — агент выделит главное: цепочка Конституция → 3185-1 → 442-ФЗ → ИППСУ, запрет выбора отсутствует, ИППСУ как механизм.
- **«Что говорит доклад про аутсорсинг? Какие 8 строк должны быть в контракте?»** — раздел 42 + приложения 43, 44.
- **«Сравни подход Новосибирской области и ДСО Серафимовский по внедрению вариативности»** — раздел 25, кейсы 14, 22.
- **«Перепиши раздел 11.3 (литий) для врача, не для кухни»** — смена аудитории через агента.

### Что НЕ спрашивать у агента

- Клинические назначения для конкретного жителя — доклад не заменяет врача.
- Юридические заключения для конкретного случая — доклад не заменяет юриста.
- Актуальные редакции НПА — источники приведены по состоянию на 17.08.2026, для свежей версии нужна платная правовая база.

### Ограничения Markdown-конверсии

- Сноски упрощены: `^1^` вместо `[^1]`. Если нужны настоящие ссылки на сноски, используйте HTML-версию.
- Сложные таблицы могут потерять выравнивание — для печати используйте PDF.
- Визуальные элементы (схемы, фигуры) — только в HTML/PDF.
- Некоторые места с особым форматированием (жирный + курсив) могут рендериться иначе, чем в HTML.
